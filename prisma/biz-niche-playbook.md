# 稼ぐ系・実用系ジャンル特化プレイブック

このナレッジは「副業／アフィリエイト／ビジネス／投資／キャリア／お金」など、いわゆる**稼ぐ系・実用系ジャンル**で投稿生成するときの追加指針。

ジャンルが該当しない場合（日常系・育児・美容・スピ系など）は**このナレッジを無視して、他のフック集とコンセプトシートに従って生成すること**。

---

## このジャンルの根本問題

稼ぐ系はThreads内で最もレッドオーシャン化したジャンル。発信者数が多すぎて、**普通に良い投稿を作るだけでは「合格点だがバズらない」**になる。

### バズらない理由TOP5

1. **既視感のある定型構造**
   - 「2種類の人間がいる」「才能の差じゃない」「単価の問題」「ジャンル選びが9割」
   - 業界の常識ロジックを業界の常識用語で並べる→読者は最初の5秒で「またこれか」と判定して離脱
2. **業界内固有名詞だけで完結**
   - 「楽天アフィvs退職代行アフィ」のような業界内比較で終わる
   - アナロジー・比喩がない＝発信者の独自視点を感じない
3. **数字が一般論レベル**
   - 「月150円」「月20万」のような他人事の数字
   - 個人的実績数字・固有名詞の方が圧倒的に強い
4. **結論が予測可能**
   - 1行目から最終行まで論理が直線的
   - 「予想を裏切る切り口」が1つもない
5. **CTAが「行動指示」になってる**
   - 「〇〇してください」「単価を見直そう」のような上から目線
   - 読者は教えられたいのではなく、共感・気づき・自己投影を求めている

## 稼ぐ系で禁止する定型表現（生成時に避けること）

以下はThreadsの稼ぐ系で過去30日に氾濫してる表現。**1つでも使ったら投稿の格が落ちる**前提で、絶対に使わないこと。

### 構文レベルの禁止
- 「〇〇には2種類の人間がいる」
- 「才能の差じゃない、〇〇の差」
- 「努力が報われないのは、〇〇が間違ってるだけ」
- 「悪いこと言わないから、一度だけ〇〇してください」
- 「断言します」「言い切ります」（連発禁止、1ヶ月に1回まで）
- 「〇〇な人、99%これやってない」（属性特化型として劣化版）
- 「これ秘密にしてほしいんですが」→「ぶっちゃけ言うと」も同様
- 「〇〇すれば月収X万」（教材臭がする）
- 「人生変わる」「景色が変わる」（情景描写なし抽象すぎ）

### 業界内クリシェの禁止
- 「楽天アフィ」「退職代行」「Wordpress」「ChatGPT」だけで完結する話
- 「単価」「ジャンル選び」「9割」「8割」を1投稿で2回以上使う
- 「再現性」「資産化」「自動化」を強調する語彙の連発

### 教材臭の禁止
- 「ステップ1〜ステップ5」のような番号リスト型
- 「〇〇の3つのコツ」「〇〇の5つの理由」
- 箇条書きで4つ以上並べる
- 「保存版」「永久保存」「教科書」（エンゲージメントベイト級にウザい）

## 稼ぐ系で機能するフックの作り方

### 1. アナロジー必須の原則
1投稿に最低1つは**業界外からの比喩**を入れる。
- 副業 → ラーメン屋／釣り／格闘技／野球／釣具屋／ゲーム
- 投資 → ボディビル／登山／料理
- アフィリエイト → 物販／マッチング／不動産仲介
- フリーランス → 漁師／農家／個人タクシー

例: 「副業のジャンル選びって、釣り場選ぶのと同じで、魚がいない池でいくら竿振っても無駄なんですよ。」

### 2. 個人的失敗の差し込み
「〇〇万溶かした」「〇年無駄にした」のような**自分の数字付き失敗**を1〜2投稿目に挿入。
これはコンセプトシートの「過去の失敗体験」フィールドから引用する。

例: 「3年で200万溶かして気づいたんですが、〇〇は『〇〇する人』しか勝てない構造でした。」

### 3. 業界の常識を裏切る一文
「実は〇〇は不要」「〇〇しないほうが結果出る」のような**逆張り**を1本に1つ。
ただし、根拠（個人体験 or 1次情報）が伴う場合のみ。根拠なしの逆張りは炎上素材。

例: 「副業で『時間管理』を頑張る人、ほぼ全員伸びません。理由は、」

### 4. 数字は個人実績優先、なければ「具体的すぎる固有名詞」
- ◎ 「月7,432円」（妙な具体性）
- ◎ 「3年2ヶ月」「112日目」
- ◎ 「Aさん（38歳・元保育士）」
- ✗ 「月10万」「3年」（一般論すぎる）

### 5. 締めは「自己投影トリガー」
「あなたはどうですか？」NG（クリシェ）。
代わりに、読者が自分の現状と照らし合わせるシーンを描写する。

例: 「もしあなたが今、〇〇〇と感じてるなら、それは才能の問題じゃない。」（NG: 才能じゃない）
→ 「もしあなたが今夜、PCの前で『また何も進まなかったな』って思ってるなら、〇〇〇」

## 稼ぐ系で機能するフック型（既存25型からピックアップ）

既存の市場フックパターン集25型のうち、**稼ぐ系で特に機能する型**は以下：

| 型 | 使用上のコツ |
|---|---|
| 4. 生データ・数字公開型 | 個人実績数字を使う。一般論NG |
| 5. 常識破壊・オワコン宣言型 | 1次情報を伴う場合のみ。根拠なしNG |
| 7. 常識否定・真実暴露型 | 業界内常識→業界外視点で否定する形 |
| 14. 本質定義型 | 抽象論禁止、具体的な行動レベルで定義 |
| 15. 厳しめ現実直視型 | 突き放し→寄り添いの順で。突き放しのままNG |
| 17. 逆張り回答型 | アナロジー必須 |
| 19. 年齢期限・後悔回避型 | 数字（年齢）と具体未来 |
| 22. 属性特化・推奨型 | 「99%」を使うのは禁止、代わりに具体属性で絞る |

逆に**避けるべき型**：
- 6. 重要宣言・有益予告型 → 「〇〇な話します」は教材臭
- 13. リスト予告型 → ステップ番号で書くと教材っぽい
- 18. 全人類推奨型 → 押し付け感が強い

## 稼ぐ系のスレッド投稿（複数連投）の構成

```
1投稿目: フック（アナロジー or 個人失敗の数字）
2投稿目: 詳細・具体例（業界外アナロジーの展開 or 数字を時系列で）
3投稿目: 理由・本質（業界の常識を裏切る視点）
4投稿目: 自分の経験との照合（個人体験の数字）
5投稿目: 自己投影トリガー（読者の現状描写）+ 軽いCTA
```

教材的な「ステップ1〜ステップ5」構成は禁止。投稿間の繋ぎは「で、」「だから」「ここで気づいたんですが」のような口語接続で。

## チェックリスト（稼ぐ系生成後の自己検証）

各投稿について：

- [ ] 既視感のある定型表現（上記リスト）が使われていない
- [ ] 業界外からのアナロジーが1つ以上ある
- [ ] 個人的実績数字 or 具体的すぎる固有名詞がある
- [ ] 業界の常識を裏切る一文が1つ以上ある
- [ ] 締めが「自己投影トリガー」になっている（行動指示じゃない）
- [ ] 教材的な番号リスト構成になっていない
- [ ] 「2種類の人間がいる」「才能の差じゃない」「悪いこと言わない」「断言します」を使っていない

すべてYESになるまでフックを書き直す。1つでもNOがあれば**「合格点だがバズらない」**ライン。
