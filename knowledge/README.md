# ナレッジ編集フォルダ

ここにあるmdファイルは、アプリのDBに保存されているナレッジをVSCode+Claude Codeで編集するための作業ファイルです。

## フォルダ構成

```
knowledge/
├── カスタム-raito_tenshoku/   ← らいとアカウント専用（自分で作ったもの）← ★主な編集対象
├── カスタム-グローバル/       ← 全アカウント共通の追加ルール（自分で作ったもの）
└── デフォルト/                ← 製品デフォルトのナレッジ（参考用・基本編集不要）
```

## ファイルの構造

各mdファイルの先頭にフロントマター（`---`で囲まれた部分）があります。

```
---
id: (DBのID — 変えない)
title: ナレッジのタイトル
type: rules / structures / custom
accountId: アカウントID or null
enabled: true / false
---

（ここからが実際のナレッジ内容）
```

**`id` は絶対に変えないでください。** DB同期に使われます。

## 編集方法

Claudeに「このファイルを編集して」と言うだけでOKです。

例:
- 「@knowledge/カスタム-raito_tenshoku/ドメインナレッジ.md を読んで、〇〇という内容を追加して」
- 「読者の内なる声ナレッジに、最近気づいた悩みパターンを追加して」

## 編集後にDBに反映する方法

編集したファイルをアプリのDBに反映するには：

### 方法1: Claude Codeに「DBに同期して」と頼む

`knowledge-sync.js` スクリプトが自動で差分を検出してDBを更新します。

### 方法2: Webアプリから手動更新

1. アプリを起動（`bash start.sh`）
2. 「設定 → ナレッジ」で対象のナレッジを開く
3. 編集した内容をコピーして貼り付け → 保存

## 注意事項

- ここを編集してもアプリに**自動では反映されません**。上の方法でDB同期が必要です
- DBを直接編集したい場合は、アプリのナレッジ画面から行うのが一番安全です
- `デフォルト/` フォルダのファイルはアップデート時に上書きされます。個人カスタマイズは `カスタム-グローバル/` に置いてください
