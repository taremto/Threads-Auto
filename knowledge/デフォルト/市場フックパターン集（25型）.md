# 市場フックパターン集（汎用テンプレ）

このファイルは、Threadsで伸びている1投稿目（フック）の25型を汎用テンプレ化したナレッジDBです。
投稿生成時に参照し、Layer / OATH / Schwartz / 投稿タイプに応じて最適なフック型を選定するために使います。

各テンプレの `{{スロット}}` 部分は、ユーザーのコンセプトシート（WHO / WHAT / FOR WHOM / VALUE / TONE）に沿って自動的に埋まります。

---

## 用語の前提

このファイルでは以下の汎用フレームワークを使います。固有のジャンル（ビジネス、健康、育児、占いなど）に依存しません。

### OATH段階（読者の問題への関わり方）
- **Oblivious（無知）**: 問題があることをそもそも知らない
- **Apathetic（無関心）**: 問題は知ってるが他人事
- **Thinking（検討中）**: 解決策を探し中
- **Hurting（苦痛）**: 今まさに困っている

### Schwartz 5段階認知（商品との距離）
- **Unaware**: 自分の問題に無自覚
- **Problem Aware**: 問題は認識してる
- **Solution Aware**: 解決策があることは知ってる
- **Product Aware**: あなたの商品の存在は知ってる
- **Most Aware**: 買う気はあって条件待ち

### 主要な心理トリガー
認知的不協和 / ツァイガルニク効果（未完了の引き） / 損失回避 / 自己関連性 / 好奇心ギャップ / 社会的証明 / 選別・排他性 / 権威性 / 希少性

### Layer（投稿の役割）
- **Layer 1**: リーチ獲得（新規フォロワー獲得）
- **Layer 2**: 信頼構築・差別化
- **Layer 3**: 収益導線

# フック型一覧（25型）

---

## 1. 結論先出し型

### 構造（テンプレート）
```
{{結論先出しの宣言}}。{{ジャンル/テーマ}}で{{達成したい状態}}したいなら、
「{{核心となる主張/行動}}」に全振りしてください。
{{当たり前のようで意外と見落とされていることを補足}}。
それは何かというと、
```

### スロットの埋め方
- **結論先出しの宣言**: 「もう答えいいますね」「結論をいいます」「先に答えだけ言います」など
- **達成したい状態**: ユーザーのターゲットが望むゴール（例: 売上を作る / 体調を整える / 関係を改善する）
- **核心となる主張/行動**: そのゴールに到達する一番のレバー

### 適した投稿タイプ
ノウハウ系 / ロードマップ系 / マインドセット系

### 適したOATH段階
Thinking / Hurting

### 例文（汎用）
- 「もう答えいいますね。{{テーマ}}で結果を出したいなら、『{{核心}}』に全振りしてください。当たり前のようですが、意外とできてません。それは何かというと、」

### 使用上の注意
- 結論を“匂わせる”だけで、本体は2投稿目以降に持ち越す
- 末尾は「、」で止めて未完了状態を作る（「。」で閉じない）

## 2. 奥義・決定版公開型

### 構造（テンプレート）
```
{{価値の最大級宣言}}。{{熱いリクエスト/緊急性の理由}}があったので、
「{{決定版/ロードマップ等}}」を書きました。
{{社会的証明（実績数字）}}、僕の{{独自メソッド名}}を公開します。
{{何ステップ/何ポイントなのかを予告}}を以下にまとめてます。
{{行動喚起}}
```

### スロットの埋め方
- **価値の最大級宣言**: 「これが奥義です」「最強の{{テーマ}}まとめ作りました」
- **独自メソッド名**: ユーザーが普段使っているメソッド名・呼び名（コンセプトシートから引く）
- **社会的証明**: 「{{X人}}の実績者が出ている」「{{Y件}}検証して分かった」など事実ベースのみ

### 適した投稿タイプ
ロードマップ系 / テンプレ・ノウハウ公開系 / 実績公開系

### 適したOATH段階
Thinking / Hurting

### 例文（汎用）
- 「最強のテンプレを作りました。{{テーマ}}で{{ゴール}}に到達するための『{{N}}ステップロードマップ』を共有します。{{社会的証明}}。リアルになぞるだけで結果出ます。0スタートから解説していきます」

### 使用上の注意
- 数字（ステップ数・実績数字）は事実ベース。盛らない
- 「これさえやれば100%」のような誇大表現は避ける

---

## 3. 希少性・限定公開型

### 構造（テンプレート）
```
{{消す/隠す匂わせ}}。{{気が引ける前置き}}けど、
{{ターゲットの困りごと}}が多そうなので、特別に公開します。
テーマは、{{秘匿性の高いトピック}}について。
よくある一般論ではなく、{{独自の視点/一次情報}}を共有します。
ぜひメモっておいてください。ではいきます
```

### スロットの埋め方
- **消す/隠す匂わせ**: 「わんちゃん消します」「鍵垢で書こうか迷ったけど」「こっそり教えますが」
- **秘匿性の高いトピック**: 一般には公開されにくい分析・裏側・データ
- **独自の視点/一次情報**: ユーザー自身の体験・観察から来る情報

### 適した投稿タイプ
一次情報・裏話系 / 差別化ポイント系 / センターピン系

### 適したOATH段階
Apathetic（自分事化させる） / Thinking

### 例文（汎用）
- 「こっそり教えますが、{{テーマ}}で{{ゴール}}を目指すなら、ベストな“順番”があります。{{社会的証明}}してきた中で見えた、黄金のテンプレートを置いておきます」

### 使用上の注意
- 「消します」系は連発するとオオカミ少年化するので頻度を抑える
- “希少性”の根拠が嘘にならないよう、本当に普段は出さない情報を出す

---

## 4. 生データ・数字公開型

### 構造（テンプレート）
```
{{価値の予告}}あげます。
{{秘匿性のニュアンス}}ですが、{{テーマ}}には、
「{{この数字がこうなったら○○}}」という指標があります。
{{社会的証明（観察ベース）}}、それをもとにして算出しました。
知っておいて損はないので、ぜひメモっておいてください。
```

### スロットの埋め方
- **価値の予告**: 「まじの生データあげます」「裏の数字出します」
- **指標**: KPI・しきい値・相関・チェックリスト的な数字

### 適した投稿タイプ
データ分析系 / 指標・KPI系 / 実績公開系

### 適したOATH段階
Thinking / Hurting

### 例文（汎用）
- 「生データあげます。{{テーマ}}には『{{指標A}}が{{X}}を超えると{{結果Y}}になりやすい』という基準があります。{{N件}}見てきて算出した数字なので、メモしておいてください」

### 使用上の注意
- 数字はサンプル数と前提を明示できる範囲で
- 「断定」より「傾向」のトーンの方が信頼が落ちにくい

---

## 5. 常識破壊・オワコン宣言型

### 構造（テンプレート）
```
{{重要宣言}}。{{今ある常識/手法}}は、{{オワコンになる/価値が下がる}}。
今後は、{{プライシング/手法/トレンドの常識}}が変わる。
{{現在のスタンダード}}は{{弱点/限界}}でもあるので、
最新の方法を、以下に{{N}}つ共有しておきます。
{{先行者利益の示唆}}
```

### スロットの埋め方
- **今ある常識/手法**: 業界で当然視されている方法・価格帯・前提
- **最新の方法**: ユーザーが先行して見つけた切り口

### 適した投稿タイプ
トレンド変化系 / 警告・注意喚起系 / 新常識提示系

### 適したOATH段階
Oblivious（気づかせる） / Apathetic（危機感）

### 例文（汎用）
- 「重要なこと言います。{{現在の常識}}は、ほぼオワコンになります。今後のスタンダードは{{新常識}}です。先にはじめて先行者利益を取りましょう」

### 使用上の注意
- 業界全否定にならないように。「これも価値はある、でもアップデートが必要」のトーンが安全
- 個人・特定企業を名指しで攻撃しない

---

## 6. 重要宣言・有益予告型

### 構造（テンプレート）
```
{{重要度の予告}}。{{テーマ/ジャンル}}についてです。
{{N}}と{{N+1}}で変わったところがあるので、覚えておいてください。
{{核心のチラ見せ：「○○が9割」「○○には2種類ある」}}。
解説すると、
```

### スロットの埋め方
- **重要度の予告**: 「めっちゃ重要なこといいます」「けっこう有益なこと言います」
- **核心のチラ見せ**: 「○○が9割」「○○には2種類あります」「○○には順番がある」

### 適した投稿タイプ
ノウハウ系全般 / 分類・整理系 / ポジショニング系

### 適したOATH段階
Thinking / Apathetic

### 例文（汎用）
- 「めっちゃ重要なこといいます。{{テーマ}}で{{ゴール}}を出すには、{{核心}}が9割です。ただ、これには2種類ありまして、解説すると、」

### 使用上の注意
- 「9割」「ほぼ決まる」は使いすぎると軽くなる。連投しない

---

## 7. 常識否定・真実暴露型

### 構造（テンプレート）
```
もう{{N}}回は言ってますが、{{誤った定説}}しても{{結果}}には繋がりません。
{{誤解の中身（こう思われがちですが）}}。まったく違います。
特に、{{ジャンル}}では、{{表面的な指標}}を集めるよりも、
{{本質的な指標}}の方がはるかに大事です。
今すぐできる施策としては、
```

### スロットの埋め方
- **誤った定説**: 業界で広く信じられているが結果に繋がらない行動
- **本質的な指標**: ユーザーが考える本当の勝ち筋

### 適した投稿タイプ
マインドセット系 / 誤解解消系 / 本質論系

### 適したOATH段階
Oblivious / Apathetic

### 例文（汎用）
- 「もう何回も言ってますが、{{誤った行動}}をしても{{ゴール}}には繋がりません。本当に大事なのは{{本質}}です。今すぐできる施策は、」

### 使用上の注意
- 「あなたは間違っている」と読者を責めず、「みんな勘違いしがち」のトーンに

---

## 8. Q&A即答型

### 構造（テンプレート）
```
Q：「{{ターゲットの具体的な悩み（口語）}}」
A：{{命令形の指示①}}しなさい。{{指示②}}しなさい。{{指示③}}しなさい。
{{数字根拠（あれば）}}。
あとは、
```

### スロットの埋め方
- **悩み（口語）**: ターゲットが実際にDM等で送ってきそうな素の悩み
- **指示**: 単発で実行できる粒度のアクション

### 適した投稿タイプ
ノウハウ系 / トラブルシューティング系 / 具体的アクション系

### 適したOATH段階
Hurting / Thinking

### 例文（汎用）
- 「Q：『{{悩み}}どうしたらいいですか？』 A：まず{{指示①}}しなさい。次に{{指示②}}。{{指示③}}も忘れずに。あとは、」

### 使用上の注意
- 命令口調が強すぎるとパワハラ感が出る。語気はキャラに合わせて調整
- 「しなさい」を全文末で連発しない

---

## 9. 直接呼びかけ・行動指示型

### 構造（テンプレート）
```
{{ターゲット属性を直接指名}}へ。
{{信頼の前置き}}、{{行動指示}}しなさい。
{{ベネフィット（数字あり）}}。
{{駄目押しの一言}}
```

### スロットの埋め方
- **ターゲット属性**: 「{{ジャンル}}見てる人へ」「{{属性}}のあなたへ」「この投稿を見た{{属性}}へ」
- **信頼の前置き**: 「悪いこと言わないから」「嘘みたいですが」「冗談抜きで」

### 適した投稿タイプ
行動喚起系 / 推奨・レコメンド系 / 成功事例系

### 適したOATH段階
Apathetic / Oblivious

### 例文（汎用）
- 「{{属性}}へ。悪いこと言わないから、{{行動}}してみて。それだけで{{ベネフィット}}が狙える。ガチで人生変わる」

### 使用上の注意
- 名指しの粒度が広すぎると刺さらない。「{{属性}}＋{{状況}}」まで絞る
- 「ヤバい」「絶対」の連発は信頼を下げる

---

## 10. 禁止リスト型

### 構造（テンプレート）
```
絶対にやってはいけない{{ジャンル/対象}}が「{{NG①}}」「{{NG②}}」「{{NG③}}」です。
解説します↓
```
または
```
{{ジャンル}}でやってはダメなことが、
1：{{NG①}} 2：{{NG②}} 3：{{NG③}} 4：{{NG④}} 5：{{NG⑤}} の{{N}}つ。
逆に言うと、これを避ければ伸びやすくなるので、解説します↓
```

### 適した投稿タイプ
警告・注意喚起系 / 失敗回避系 / ジャンル選定系

### 適したOATH段階
Oblivious（危険を教える） / Apathetic（危機感）

### 例文（汎用）
- 「絶対やってはいけない{{ジャンル}}は『{{NG①}}』『{{NG②}}』『{{NG③}}』です。理由は、」

### 使用上の注意
- 個別の人・サービス名を名指しで否定しない（炎上リスク）
- 否定で終わらず、後半で「正解」を提示する

---

## 11. ガチ最強・ツール推奨型

### 構造（テンプレート）
```
{{最強宣言}}。{{希少性の前置き}}けど、
{{ターゲット属性}}は全員{{ツール名/手法}}使った方がいい。
{{メリット①}}。{{メリット②}}。{{メリット③}}。
具体的な使い方はというと、
```

### スロットの埋め方
- **最強宣言**: 「ガチ最強」「これは全員使うべき」「神ツール見つけた」
- **希少性の前置き**: 「知らない人多いけど」「あんま広まってないけど」

### 適した投稿タイプ
ツール紹介系 / 効率化系 / テック系

### 適したOATH段階
Thinking / Apathetic

### 例文（汎用）
- 「ガチ最強。知らない人多いけど、{{属性}}は全員{{ツール}}使った方がいい。{{メリット}}。具体的な使い方はというと、」

### 使用上の注意
- ツール名は固有名詞を出した方が刺さる（カテゴリ語より具体的に）
- アフィリンクを本文に貼らない（プロフ/固定誘導）

## 12. 肯定・承認型

### 構造（テンプレート）
```
忘れてはダメなのが、{{今のあなたの状態}}は凄いってこと。
{{世間の常識との比較で発展途上感を出す}}。
{{今その地点にいることがどれだけ凄いかの言語化}}🥺
```

### スロットの埋め方
- **今のあなたの状態**: ターゲットが達成してる小さな成果（ただし読者は「これくらい当たり前」と思ってる）
- **世間との比較**: 一般人がそれをいかに知らないか/できないかの描写

### 適した投稿タイプ
マインドセット系 / モチベーション系 / コミュニティ形成系

### 適したOATH段階
Hurting（励ます） / Thinking（安心させる）

### 例文（汎用）
- 「忘れてはダメなのが、{{今の状態}}が作れてる時点で凄いってこと。世の中ほとんどの人が{{平均的な状態}}なんだから、ここまで来れてるのは異常です」

### 使用上の注意
- 過剰な持ち上げは逆効果。事実ベースで凄さを言語化する

## 13. リスト予告型

### 構造（テンプレート）
```
{{ジャンル}}で{{形容詞}}{{対象}}{{N}}選
1：{{項目①}}
2：{{項目②}}
3：{{項目③}}
…
それぞれなぜ{{形容詞}}か、軽く解説します↓
```

### 適した投稿タイプ
まとめ系 / ランキング系 / ジャンル選定系

### 適したOATH段階
Thinking / Oblivious

### 例文（汎用）
- 「{{ジャンル}}で伸ばしやすい{{対象}}{{N}}選 1：{{項目①}} 2：{{項目②}} … それぞれ解説します↓」

### 使用上の注意
- 並列情報が5個以上あるときに使う（少ないなら文章型の方が読みやすい）
- 末尾を「。」で閉じない

---

## 14. 本質定義型

### 構造（テンプレート）
```
{{テーマ}}は「{{本質ワード}}」です。
{{なぜそうなのかの理由を1〜2行}}。
{{社会的証明 or アルゴリズム/構造的根拠}}（気づいてる人も多いはず）。
裏話もしておくと、
```

### 適した投稿タイプ
本質論系 / マインドセット系 / 戦略系

### 適したOATH段階
Oblivious / Apathetic

### 例文（汎用）
- 「{{テーマ}}は『{{本質ワード}}』です。理由は{{構造的根拠}}。裏話もしておくと、」

### 使用上の注意
- 本質ワードは自分独自の表現にする（他人の概念をパクらない）

---

## 15. 厳しめ現実直視型

### 構造（テンプレート）
```
ちょっと厳しいこといいますが、{{甘い期待}}って思ってる人多いんですけど、
それは「{{楽観的前提①}}」「{{楽観的前提②}}」「{{楽観的前提③}}」ってわけではなくて、
「{{現実①}}」「{{現実②}}」「{{現実③}}」ができた人が、
ようやく{{ゴール}}に行ける、って話なので、ここ間違えないように！
逆に言うと、ここまでできれば、{{先のポジティブな未来}}🔥
```

### 適した投稿タイプ
マインドセット系 / 現実直視系 / モチベーション系

### 適したOATH段階
Apathetic / Thinking

### 例文（汎用）
- 「厳しめに言うと、{{ゴール}}は『楽して』『短期間で』いけるものではなく、{{現実的な努力}}が前提です。逆にここまでできれば、{{未来}}」

### 使用上の注意
- 否定で終わらず、必ずポジティブ転換で締める
- 上から目線にならないように、自分の経験ベースで語る

```
の発信/選択が{{有利な理由}}。

```

### 適した投稿タイプ
ジャンル選定系 / 推奨・レコメンド系 / 戦略系

### 適したOATH段階
Thinking / Oblivious

### 例文（汎用）
- 「断言するけど、{{テーマ}}やるなら ・{{属性A}}なら{{選択A}} ・{{属性B}}なら{{選択B}} がベスト。ちなみに別の軸でいうなら、」

## 17. 逆張り回答型

### 構造（テンプレート）
```
「{{ありがちな質問}}？」って聞かれるけど、{{逆張りの回答}}です。
{{代替案}}でいいです。{{逆張りの理由（コスト・難易度・効果）}}。
じゃあ、{{元の選択肢}}するのは誰かっていうと、
```

### 適した投稿タイプ
推奨・レコメンド系 / 初心者向け系 / 選択肢整理系

### 適したOATH段階
Thinking（別の選択肢を示す） / Apathetic（ハードルを下げる）

### 例文（汎用）

## 23. 選別・逆オファー型

### 構造（テンプレート）
```
{{属性}}な人は読まないでください／{{条件}}な人は申し込まないでください。
{{排除する理由：なぜ成果が出ないか・なぜ向いていないか}}。
逆に、{{ICP像}}な人は、{{得られる価値}}が刺さると思います。
刺さった人だけ{{次のアクション}}してください。
```

### 適した投稿タイプ
商品紹介・セールス系 / マインドセット系 / ポジショニング系

### 適したSchwartz認知段階
Product Aware / Most Aware

### 適したLayer
Layer3が最適。Layer2でも差別化訴求として使える。

### 心理トリガー
排他性 / 自尊心 / 損失回避 / 好奇心

### 例文（汎用）
- 「{{条件}}な人は申し込まないでください。お互いの時間がもったいないので。逆に、{{ICP像}}な人には刺さると思います」
- 「『{{楽したい系のセリフ}}』って人、悪いけどお断りしてます。理由は簡単で、」
- 「{{条件}}を超えてない人には刺さらないかもしれないです。でも{{条件超え}}なのに『次のステージにいけない』って人は、たぶん心当たりあるはずです」

### 使用上の注意
- 排除の理由は「見下し」ではなく「お互いのため」のスタンス
- 排除しっぱなしで終わらせない（必ず「逆にこういう人には刺さる」を入れる）
- 頻度は週1回以下。やりすぎると上から目線キャラになる
- Layer3で使うときCTAは「刺さった人だけ{{固定/プロフ}}見てください」程度の軽さに

## 24. 判断軸提示・教材否定型

### 構造（テンプレート）
```
{{一般的解決策}}に聞いても答えが出ない問題がある。
それは「{{個別最適化が必要な判断}}」。
{{なぜAI/教材/独学では届かないか}}。
{{N人見てきて分かった一次情報}}、答えはこうです：{{核心ワード}}。
ここだけは、{{一般的解決策}}には書いてない。
```

### スロットの埋め方
- **一般的解決策**: AI / 教材 / 動画 / 書籍 / 独学 / 外部相談など、ターゲットがすでに試している手段
- **個別最適化が必要な判断**: 「自分の場合、次に何をすべきか」のような状況依存の問い
- **核心ワード**: ユーザーの差別化の核（コンセプトシートのVALUEから引く）

### 適した投稿タイプ
差別化訴求系 / 本質論系 / ポジショニング系

### 適したSchwartz認知段階
Solution Aware / Product Aware

### 適したLayer
Layer2が最適。Layer3でも使える。

### 心理トリガー
認知的不協和 / 好奇心ギャップ / 権威性 / 希少性

### 例文（汎用）
- 「{{AI/教材}}に聞いても絶対に答えが出ない問題がある。それは『あなたの場合、次に何をすべきか』の判断です」
- 「{{N}}人以上見てきて分かったんですけど、{{結果A}}が出る人と出ない人の違い、情報量の差じゃないんです」
- 「ぶっちゃけ、ノウハウはもう足りてます。{{AI/教材}}で8割は分かる。じゃあなぜ成果が出ないのか。足りてないのは『{{独自の差別化軸}}』です」

### 使用上の注意
- 「教材が無駄」と言い切るのではなく「教材“だけ”では解決しない問題がある」スタンス
- 必ず自分の一次情報（実績数）を根拠として出す
- Layer2で使うならCTAなしか軽いプロフ誘導。Layer3なら無料診断/相談へ

## 25. ビフォーアフター・成果事例型

### 構造（テンプレート）
```
{{受講生/相談者/お客さん}}の{{属性}}、開始{{期間}}で{{達成した成果}}した話。
{{ビフォー：どんな状況だったか}}
↓
{{ターニングポイント：何を変えたか}}
↓
{{アフター：どうなったか（具体数字）}}
{{自分（発信者）の役割を控えめに}}。実行したのは{{受講生本人}}です。
```

### スロットの埋め方
- **受講生/相談者/お客さん**: ユーザーの提供する商品・コンサル・相談を受けた人の汎用ラベル。コンセプトシートに合わせて変える
- **発信者の役割**: 「{{切り口/判断軸/きっかけ/視点}}を渡しただけ」など、参謀ポジションを示す表現

### 適した投稿タイプ
成果事例・ケーススタディ系 / 実績公開系 / 社会的証明系

### 適したSchwartz認知段階
Product Aware（最も効果的） / Solution Aware

### 適したLayer
Layer2が基本（成果見せがメインの場合）。Layer3でも使える（CTAが強い場合）。

### 心理トリガー
社会的証明 / 自己関連性 / 好奇心 / 希望

### 例文（汎用）
- 「{{受講生属性}}が、{{期間}}で{{ビフォー}}→{{アフター}}になった話。何をしたか。正直、{{自分}}がやったのは1つだけです」
- 「『{{相談内容}}』って人が、{{期間}}後に{{結果}}を超えた。何を変えたか。{{変えなかったもの}}は同じです。変えたのは{{ポイント}}だけ」

### 使用上の注意
- 主語は「{{受講生/相談者}}」であって「自分」ではない。「自分がすごい」ではなく「この人がすごい」のスタンスを守る
- 具体数字（期間、実数、変化幅）を入れる
- 本人が特定されない範囲で書く（許可がなければ名前は出さない）
- 「自分がやったのは{{切り口/判断軸}}を渡しただけ」のフレーズで参謀ポジションを毎回強化

# 共通の使い方原則

- **同じ型を1バッチ内で連発しない**: 心理トリガーが被ると読者が飽きる
- **末尾を「。」で閉じない**: 「、」「⇩」「：」「？」「体言止め」のいずれかで未完了状態を作る（ツァイガルニク効果）
- **数字と固有名詞を入れる**: フックには「期間 / 人数 / 回数 / 金額 / 倍率」のいずれかと、ジャンルの磁力ワード（カテゴリ語より固有名詞優先）を含める
- **ハッシュタグ・エンゲージメントベイトは禁止**: 「いいねで○○」「コメントで○○」「保存した人に」はリーチ激減
- **結論を1投稿目で言い切らない**: 結論を“匂わせる”だけにして、本編を読む理由を残す
- **コンセプトシートのトーン・一人称・キャラに合わせる**: テンプレの命令口調はあくまでデフォルト。ユーザーのキャラに寄せて言い換える
