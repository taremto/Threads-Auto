# バズフックパターン集（実バズ247件から抽出した型）

**目的**: 1投稿目（フック）の精度を最大化するためのテンプレ集。
2026年4月時点でThreadsで100万view超を記録した247件のバズ投稿を構造分析し、再現性のあるパターンに落とし込んだもの。

## 使い方の原則

- **1バッチ6本のうち、ここの型は2本以上に同じ型を使わないこと**（既存rules準拠）
- パターンの「{{スロット}}」部分はコンセプトシートのテーマ・ペルソナに沿って必ず固有化する
- 実例の文言をそのままコピーするのではなく、構造を借りて新しい一文を作る
- 数字（view数）は内部参考情報。投稿本文に含めない
- 「保存した人に」「コメントで○○」等のエンゲージメントベイトはこの型からは生成しない

## 【型1】権威者の逆説引用 ★★★最強

### 構造
```
{{有名人/専門家}}が言ってた。「{{逆説的な真理一文}}」
{{最初の反応}}。でも{{気づき/腑に落ちた感覚}}。
{{理由・展開へ}}
```

### スロット
- **有名人/専門家**: マツコ／ひろゆき／タモリ／著名選手・歌手／〇〇の名医／精神科の先生／保育園の先生／救命センター看護師／歯医者／
- **逆説的な真理**: 一見ネガティブだが本質的・直感に反するが頷ける命題
  - 例: 「悪口を言わない人は信頼できない」「言い返せない人は優しい」「不機嫌を撒き散らす人は子ども」「ナメられる人は最初の1回を許してる」
- **最初の反応**: 最初は意味わからなかった／目から鱗だった／胸に刺さった／聞いた瞬間ゾッとした
- **気づき**: でも本当その通り／なるほどと思った／これ知らない人多い

### 実例（実バズ）
- 「マツコが言ってた。『悪口を言わない人って、信頼できないのよ』これ、最初は意味わからなかった。でも本当その通り。」
- 「マツコが言ってた。『言い返せない人って、頭が悪いんじゃなくて優しいのよ』。むかつくことを言われて、その場で言い返せなかった全人に伝えたいことがある。」
- 「精神科の先生に『不登校の子より先にメンタル壊れるのって誰だと思う？』って聞いたら、『担任』とか『本人』って答えると思ったんだけど、」
- 「ひろゆきが言ってた『子どもにイライラして怒鳴っちゃう人への対処法』が目から鱗だった。」

### 使うべきテーマ
人間関係・教育・育児・メンタル・人生訓・気づき系

## 【型2】タブー匂わせ・自己開示前置き ★★★

### 構造
```
{{タブー匂わせ一文}}。
{{補足の制約}}。
{{本題への導入}}。
```

### スロット
- **タブー匂わせ**:
  - 「{{家族}}にバレたら消します」
  - 「鍵垢にします」
  - 「ちょっとエグいから聞いてほしい」
  - 「少し{{デリケート領域}}な話するね」
  - 「ごめんね。ちょっと{{気が引ける領域}}な話します」
  - 「正直、ゾッとした」
  - 「もう限界です、正直に言います」
  - 「謝罪文。すみません」

### 実例
- 「旦那にバレたら消します。または、鍵垢にします。掃除してたら、旦那の日記を見つけました。」
- 「ちょっとエグいから聞いてほしい🫩知り合いの肥満治療の名医に〜って泣く泣く相談したら、」
- 「ごめんね。ちょっと匂う話します。エレベーターに乗っていたら〜」
- 「正直、ゾッとした。仲のいい友人が『最近、自分の口臭が気になってて…』って相談してきた。」

### 使うべきテーマ
夫婦・家庭・人間関係の本音・体験告白・気まずい話

### 注意
- 嘘や煽りすぎはNG（コミュニティガイドライン違反のリスク）
- 「鍵垢にします」を使う場合、本当に消す可能性のある内容を扱う時のみ

## 【型3】専門家ポジション宣言 ★★★

### 構造
```
{{ポジション宣言}}。
{{断言/呼びかけ}}。
{{ファクト or ノウハウへ}}。
```

### スロット
- **ポジション宣言**: 私は〇〇です／〇〇の先生が言ってた／元〇〇の{{職業}}だから言いますが／〇〇歴〇年の私が
- **断言**: そろそろ覚えてください／知ってほしい／伝えたいことがある／一番伝えたいのは

### 実例
- 「私は豆腐屋です。そろそろ覚えてください。木綿豆腐は『食べるプロテイン』」
- 「歯医者が思う、虫歯が少ない子の家庭の共通点。」
- 「119番通報があって、56歳の女性の自宅に向かった。」（救命視点）
- 「ママになり、メンタルを一度壊した元救命センターの看護師だから言いますが、」
- 「アレルギーのことをちゃんと知ることは、自分の子どもを守ることと同義やねん。だから、アレルギー科ナース」

### 使うべきテーマ
専門知識共有・ノウハウ系・仕事観・職業視点の気づき

## 【型4】事件・場面導入（情景フック） ★★

### 構造
```
{{時間/場所/状況}}、{{出来事の発生}}。
{{？！な反応}}。
```

### スロット
- **時間/場所/状況**: 昨日／今日／コインパーキングで／仕事中／授業参観で／病院で／お店で
- **出来事の発生**: 具体的な事実1つ（読者が場面を映像化できる粒度）
- **反応**: 「？」／「えっ…」／頭が真っ白／「は？」／焦って〜

### 実例
- 「コインパーキングに車停めて友達とランチへ。戻って精算すると『？』安すぎる、、。」
- 「仕事中夫からの電話『次男(1才)が階段から落ちた！病院連れてく！』」
- 「昨日ね、小4の息子と怒鳴り合いになって、夜の９時に息子が家を飛び出して行ったんです。」
- 「授業参観で、娘が『将来の夢』を発表していた。」
- 「産後3ヶ月のある夜、妻がお風呂上がりに思い詰めた顔で言った。『ねぇ...なんか、アソコから何か出て触れるの』」

### 使うべきテーマ
体験談・夫婦・育児・家族エピソード・職場の出来事

### コツ
- 「いつ・どこで・誰が・何が起きたか」を1〜2文で完結に
- 余計な背景説明を入れず、いきなり場面に飛び込む

## 【型5】驚きファクト共有 ★★

### 構造
```
{{驚き起点}}。{{衝撃的な事実}}。
{{専門用語/根拠/出典}}。
{{詳細展開へ}}。
```

### スロット
- **驚き起点**: 知らなかった／最近知って一番衝撃だったやつ／前にとある方から聞いたんですけど／調べたらヤバかった
- **衝撃的な事実**: 数字 or 直感に反する事実1個（短く強く）

### 実例
- 「知らなかった。妊娠すると、赤ちゃんの細胞が27年以上、ママの体の中に生き続けるんだって。『マイクロキメリズム』って言うんだけど、」
- 「最近知って一番衝撃だったやつ。『シナモンは血糖値を下げる』って聞いてスーパーのシナモンパウダーを毎朝〜」
- 「前にとある方から聞いたんですけど、会員カードなどを作る時に書く住所の最後にその会社が分かるように、例えばA社なら『A』って書いておくと情報流出した際に〜」

### 使うべきテーマ
雑学・健康・ライフハック・お金・教養系

## 【型6】感情吐露・本音1行 ★★

### 構造
```
{{強い感情の塊1行}}。
{{文脈・理由・背景の展開へ}}。
```

### スロット
- **強い感情**: 共感・嫉妬・怒り・嘆息・諦め・歓喜
- パターン文例:
  - 「ぜーんぶ羨ましい」
  - 「俺、〇〇が嫌いでさ」
  - 「私、{{属性}}なの！！！！」
  - 「{{家族}}って何で〇〇なの？」
  - 「もう限界です、正直に言います」
  - 「たぶん一生忘れない。」

### 実例
- 「ぜーんぶ羨ましい / 私が欲しいもの全部持ってる」
- 「俺バカな奴が嫌いでさ。マンションの目の前にこの寒い中震えながら工事してるやつらいてさ、」
- 「嫁って何であんなうるさいの？」
- 「私シングルなの！！！！」
- 「たぶん一生忘れない。」

### 使うべきテーマ
本音・愚痴・ぼやき・自己開示・人間関係

### 注意
- 怒りの方向は「人」ではなく「状況」「価値観」に向ける
- 個人攻撃にならないように

## 【型7】呼びかけ・参加型 ★★

### 構造
```
{{フランクな呼びかけ}}！
{{お題提示}}やらない？／教えて／何が見える？
{{自分の例1つ}}。
```

### スロット
- **呼びかけ**: ねぇ、暇な人おる？／みんなーー！／〇〇な人いる？／突然だけど
- **お題**: あるある選手権／〇〇な瞬間／好きな〇〇／〇〇したことある人

### 実例
- 「ねぇ、暇な人おる？久しぶりに全国の母ちゃん口癖あるある選手権やらない？『水筒出して』対戦お願いします。」
- 「もしあなたが右脳型ならクジラが見えるでしょう。もし左脳型ならキリンが見えるでしょう。何が見えますか？」
- 「みんなーーーー！！大丈夫ーーーー？？！！」

### 使うべきテーマ
あるある共有・ライトな質問・コミュニティ感

### 注意
- 「いいねで○○届く」「コメントで○○」等のベイトは絶対NG
- 自然な雑談トーンで質問を投げる

## 【型8】警告・要注意系 ★

### 構造
```
{{警告ヘッダ}}。{{対象}}は{{条件}}。
{{理由展開へ}}。
```

### スロット
- **警告ヘッダ**: 【警告】／【知らないと損】／正直に言います／要注意です
- **対象**: 親が元気なうちに／〇〇する前に／〇〇な人

### 実例
- 「【警告】親が元気なうちに絶対に見てください。亡くなった直後、悲しむ暇もなく『14日以内の手続きラッシュ』」
- 「正直に言います。退職月を気にせず決めている方、1〜4月退職は要注意です。理由は、」

### 使うべきテーマ
お金・手続き・健康・キャリア・家族

### 注意
- 煽りすぎない（不安喚起→解決提示の順守）
- 根拠のない警告は絶対NG

## 【ツリー全体構造1】逆説引用→納得→展開

```
1投稿目（フック）: 【型1】権威者の逆説引用
2投稿目: 「これ、最初は意味わからなかった」+ 文脈・きっかけ
3投稿目: 「でも本当その通り」+ 理由①（具体例または論理）
4投稿目: 理由②または対比例
5投稿目: 自分への落とし込み or 読者への問いかけ（自然な疑問）
```

### 該当バズ
