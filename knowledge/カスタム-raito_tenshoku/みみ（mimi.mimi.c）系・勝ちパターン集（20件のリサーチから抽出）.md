## 【型1】「何で〇〇なのに〇〇なんだろう。世の中理不尽すぎる。」怒り独り言フック ★★★

このアカウント最高バズ（1,072いいね）を出した固有フレーズ。怒りを他者にぶつけるのではなく「独り言」として呟くトーンが、このアカウントらしさを保ちながら共感を最大化する。

### 構造
```
何で{{理不尽な対比A（原因側・加害側）}}は{{ノーダメージの状態}}で、
{{自分・被害側}}は{{割を食った状態}}になるんだろう。
世の中理不尽すぎる。
{{「〜って思ったことあるんだけど、みんなはそんな経験ない？」などゆるいCTA（任意）}}
```

### スロット
- **「何で〜なのに〜なんだろう」**: 対比は「加害側が無傷 / 被害側が退場・損をする」構造
  - 「何でお局さんはノーダメージで、私が適応障害と退職になるんだろう。」
  - 「何で問題を起こした人は昇進して、真面目にやってた人が辞めることになるんだろう。」
  - 「何でパワハラした上司はそのままで、された側が休職になるんだろう。」
- **「世の中理不尽すぎる」**: 固定フレーズ。変えない。「世の中、理不尽すぎる…」のバリエーションも可
- **CTA（任意）**: 「って思ったことあるんだけど、みんなはそんな経験ない🥹？」「って定期的に思ってしまう私がいる🫠」など独り言調で締めてもよい

### 実例（このアカウントのリサーチから）
- 「何でお局さんはノーダメージで、私が適応障害と退職になるんだろう。世の中理不尽すぎる。って思ったことあるだけど、みんなはそんな経験ない🥹？」
- 「何で私はメンタル壊して退職なのに、原因作った人は何事もなく働き続けてるんだろう。世の中、理不尽すぎる… って定期的に思ってしまう私がいる🫠」

### 使うべきテーマ
職場の理不尽（お局・パワハラ上司・評価制度の歪み）、メンタル壊した側が損をする構造全般。転職を考えているフォロワーの「自分が悪くない」という気持ちを肯定するコンテンツに使いやすい

### 注意


- **「3つある🐝」**: 「3つ」という数字と「🐝」の組み合わせがこのアカウントの固有記号。変えない
- **背景・問題意識**: 「フルリモートで検索しても出てこない」「エージェントに頼っても見つからない」など「みんなが困ってること」を1文で添える

## 【型3】「適応障害になって〇〇したこと」内省・気づきフック ★★

「適応障害になって」という前置きで体験の重さを示してから気づき・発見・喪失を語る型。データ中3件登場（626、372、229いいね）。このアカウントの「静かな誠実さ」が最も出る型。

### 構造
```
適応障害になって{{動詞 or 名詞（気づいたこと/失ったもの/初めて知ったこと）}}。

{{体験・気づきの内容を2〜4文で語る}}
{{「〜なんだよね。」「〜たよ。」など静かな締め（任意：「でも〜、ちゃんと〜たよ」の希望の一言も可）}}
```

### スロット
- **「適応障害になって〇〇」**: 「思ったんだけど、」「初めて知ったこと。」「失ったもの。」が実績あり。他に「やめたこと。」「気づいたこと。」など
- **体験内容**: 「自分のことだ」と思わせる具体的な体験・感情・気づき。一般論を並べるのではなく「私は〜だった」一人称で語る
  - 「心療内科の待合室には、普通のサラリーマンもOLも学生も、色んな人がいた。「心が壊れるのは、特別なことじゃないんだ」って気づいて、少し楽になったな。」
  - 「好きだったことへの興味。普通に眠れる夜。何も考えずに笑える瞬間。」（喪失の列挙）
- **締め（希望の一言）**: 「でも全部、戻ってきた。時間はかかったけど、ちゃんと戻ってきたよ。」のように「回復の余地がある」ことを示すと共感がさらに広がる

### 実例（このアカウントのリサーチから）
- 「適応障害になって思ったんだけど、もしかしなくても仕事って「仕事内容」より「一緒に働く人」の方が重要なんじゃないかな？」
- 「適応障害になって初めて知ったこと。心療内科の待合室には、普通のサラリーマンもOLも学生も、色んな人がいた。「心が壊れるのは、特別なことじゃないんだ」って気づいて、少し楽になったな。」
- 「適応障害になって失ったもの。好きだったことへの興味。普通に眠れる夜。何も考えずに笑える瞬間。でも全部、戻ってきた。時間はかかったけど、ちゃんと戻ってきたよ。」

### 使うべきテーマ
適応障害・うつの体験談、「環境のせい」「自分が弱いわけじゃない」という気づき、メンタル回復のプロセス。転職文脈では「なぜ転職しようと思ったか」の原点として使える

### 注意
このアカウントのトーンは「静かで誠実」。体験談を大げさにしない。「〜だったな。」「〜たよ。」という落ち着いた語尾を維持すること

## 【型4】Before/After フルリモート体験報告型 ★★

「前職（地獄）→ 今の環境（感動）」の対比で読者に「こっち側に来られる」希望を見せる型。648いいねを記録。HSP・刺激過敏の人に特に刺さる。

### 構造
```
フルリモート正社員になって驚いたこと。

{{今の環境（After）の事実をテンポよく列挙}}

前職は、{{Before（前職の辛さ）を1文で対比}}から、この環境が信じられなかった😂
「{{感動の一言セリフ}}」って感動した。
{{ターゲットへの推薦文 or 締め}}
```

### スロット
- **「フルリモート正社員になって驚いたこと。」**: 固定フックフレーズ
- **After列挙**: 「会議、全部オンライン。」「チャットで完結する仕事が多い。」「電話、ほぼかかってこない。」などテンポよく短文で並べる
- **Before対比**: 「前職は、電話と突然の呼び出しばっかりだったから、」のように前職の辛さを1文で添える
- **感動セリフ「」**: 「こんな働き方あるんだ」のようにシンプルな感動を「」で切り取る
- **締め**: 「HSPとか、刺激に弱い人には本当におすすめ。フルリモート、もっと広まってほしい。」など共感ターゲットへの推薦

### 実例（このアカウントのリサーチから）
- 「フルリモート正社員になって驚いたこと。会議、全部オンライン。チャットで完結する仕事が多い。電話、ほぼかかってこない。前職は、電話と突然の呼び出しばっかりだったから、この環境が信じられなかった😂「こんな働き方あるんだ」って感動した。HSPとか、刺激に弱い人には本当におすすめ。フルリモート、もっと広まってほしい。」

### 使うべきテーマ
フルリモート・フレックス・在宅ワークのBefore/After。転職後の「こんな職場があった」という体験報告。HSP・内向型・刺激過敏の人に響く働き方の変化

### 注意

## 【型5】「逃げていい」後押し体験談型 ★★

「転職先決まってから辞めなよ」「頑張ろう」という世間の常識に対して、自分の体験から「私はそうじゃなかった」と静かに返す型。167〜344いいね。読者の背中を押す。

### 構造
```
「{{世間の常識・よく言われること}}」ってよく言われるけど、
{{なぜ自分にとってそれができなかったか・それが違ったかを1文}}
{{「〜を後悔してない。」「〜がなかったら今の私はなかった」などの決意・肯定の締め}}
```

または：
```
{{経歴（適応障害→休職→退職）}}した私は学んだ。
「{{学んだ教訓を一言で}}」は絶対ダメ。
{{その理由・補足を1〜2文}}
{{「逃げることも、勇気。」などの締め}}
```

### スロット
- **世間の常識フレーズ**: 「転職先が決まってから辞めなよ」「あと少しだけ頑張ろう」「限界まで頑張れ」など
- **自分の体験からの反論**: 「メンタルが限界のときにまともな就活なんてできなかった。」「限界を超えたら、心は簡単には戻らない。」
- **締めの肯定文**: 「逃げるように辞めたことを後悔してない。あのとき辞めていなかったら、今の私はなかったと思う。」「逃げることも、勇気。」

### 実例（このアカウントのリサーチから）
- 「「転職先が決まってから辞めなよ」ってよく言われるけど、メンタルが限界のときにまともな就活なんてできなかった。逃げるように辞めたことを後悔してない。あのとき辞めていなかったら、今の私はなかったと思う。」
- 「適応障害→休職→結局退職した私は学んだ。「あと少しだけ頑張ろう」は絶対ダメ。限界を超えたら、心は簡単には戻らない。我慢することが美徳じゃない。逃げることも、勇気。」
- 「メンタル壊れた職場に戻るのはキツい。適応障害で休職中にそう思ったから、私は転職することにしたよ。復帰することが絶対の正解じゃないと思う。」

### 使うべきテーマ
退職・転職のタイミング、「限界まで頑張ることが正解じゃない」という価値観の転換、休職中・退職後に次を決めずに動いていい理由。転職を迷っているフォロワーの最後の一押しとして機能する

### 注意
このアカウントのトーンは押しつけない。「私はこうだった」「私はそう思う」という一人称で語り、正解を押し付けない形を維持すること
