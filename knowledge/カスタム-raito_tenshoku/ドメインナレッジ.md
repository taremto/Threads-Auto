## 2. パワーハラスメントに関する専門知識

### 2-1. パワーハラスメントの定義

厚生労働省の「あかるい職場応援団」では、職場のパワーハラスメントを、以下の3要素をすべて満たすものとして整理している。

1. 優越的な関係を背景とした言動
2. 業務上必要かつ相当な範囲を超えたもの
3. 労働者の就業環境が害されるもの

ここで重要なのは、単に「上司に怒られた」「注意された」だけで、すべてがパワーハラスメントになるわけではないという点。

客観的に見て、業務上必要かつ相当な範囲で行われる適正な業務指示や指導は、パワーハラスメントには該当しない。

### 2-2. パワハラ判断で重要な観点

パワハラかどうかを考える時は、感情だけではなく、以下を分けて見る必要がある。

- 誰が誰に対して行ったのか
- 立場の優位性があったか
- 業務上必要な指導だったか
- 指導の範囲を超えていたか
- 人格否定が含まれていたか
- 継続的に行われていたか
- 業務に支障が出ているか
- 心身の不調につながっているか
- 働く環境が害されているか

### 2-3. パワーハラスメントの6類型

厚生労働省は、職場のパワーハラスメントの典型例として、以下の6類型を示している。

| 類型 | 内容 |
|---|---|
| 身体的な攻撃 | 暴行・傷害など |
| 精神的な攻撃 | 脅迫、名誉毀損、侮辱、ひどい暴言など |
| 人間関係からの切り離し | 隔離、仲間外し、無視など |
| 過大な要求 | 業務上明らかに不要なことや遂行不可能なことの強制など |
| 過小な要求 | 能力や経験とかけ離れた程度の低い仕事を命じる、仕事を与えないなど |
| 個の侵害 | 私的なことに過度に立ち入ることなど |

### 2-4. 上司との関係で起こりやすい具体例

#### 精神的な攻撃

- 人前で怒鳴る
- ミスではなく人格を否定する
- 「だからダメなんだ」と繰り返す
- 質問しただけで強く責める
- 他の社員と比較して貶める
- ため息や舌打ちで萎縮させる

#### 人間関係からの切り離し

- 必要な情報を共有しない
- 自分だけ会議に呼ばれない
- 質問しても無視される
- チーム内で孤立させられる
- 他の社員には教える内容を自分には教えない

#### 過大な要求

- 明らかに終わらない量の仕事を振る
- 教育なしで責任だけ負わせる
- 短すぎる期限を押し付ける
- 本来の業務範囲を超える仕事を継続的に任せる
- 失敗した時だけ本人の責任にする

#### 過小な要求

- 本来任せるべき仕事を与えない
- 雑用だけを長期間続けさせる
- 能力と経験に見合わない単純作業のみをさせる
- 成長機会を意図的に奪う

#### 個の侵害

- 休日の過ごし方を詮索する
- 恋愛や結婚について踏み込む
- 家庭環境に過度に立ち入る
- 私生活の情報を職場で話題にする

### 2-5. 注意が必要な表現

専門性を保つためには、「それは絶対パワハラ」と断定しない方がよい。

適切な表現は以下。

| 避けたい表現 | 望ましい表現 |
|---|---|
| それは絶対パワハラ | パワハラに該当しうる要素があります |
| 上司が100%悪い | 行為・頻度・影響を分けて整理する必要があります |
| すぐ訴えた方がいい | まず記録と相談先の確保が必要です |
| 我慢する必要はない | ひとりで抱えず、相談できる状態を作ることが大切です |

## 3. 退職に関する専門知識

### 3-1. 労働者には退職の自由がある

厚生労働省の「確かめよう労働条件」では、無期労働契約の場合、会社が退職を認めないと言っても、労働者が退職届を提出するなど退職の申し入れをすれば、原則として2週間経過した時点で労働契約は終了すると説明している。

つまり、退職は上司の許可を得るものではなく、労働者の意思表示として扱われる。

### 3-2. 無期労働契約と有期労働契約の違い

#### 無期労働契約

正社員など、期間の定めがない雇用契約。

民法上、原則として退職の申し入れから2週間で契約終了となる。

#### 有期労働契約

契約社員、派遣社員など、契約期間が決まっている雇用契約。

契約期間中の退職については、やむを得ない事由がある場合や、契約内容によって扱いが変わる可能性がある。

### 3-3. 退職に関する誤解

| 誤解 | 整理 |
|---|---|
| 上司が認めないと辞められない | 退職は原則として労働者の意思表示で成立する |
| 退職届を受け取ってもらえないと辞められない | 受領拒否された場合でも、意思表示の記録が重要になる |
| 引き継ぎが終わるまで辞められない | 引き継ぎは重要だが、無制限に退職を妨げる理由にはならない |
| 退職理由を詳しく話さないといけない | 退職理由は詳細に説明する義務があるわけではない |
| 人間関係で辞めるのは甘え | 人間関係は実際に転職理由として多い |

### 3-4. 退職勧奨と退職強要

厚生労働省は、退職勧奨を「労働者自身の意思で退職するように勧めるもの」と説明している。

退職勧奨そのものは、必ずしも違法ではない。

ただし、以下のような場合は問題になりうる。

- 長時間にわたり退職を迫る
- 何度も繰り返し退職を迫る
- 拒否しているのに面談を続ける
- 退職届を書くよう強く迫る
- 退職しないと不利益があるように伝える
- 侮辱的な言葉で退職を迫る

### 3-5. 退職前に整理すべき要素

退職判断では、以下の要素を分けて整理する必要がある。

| 項目 | 確認すること |
|---|---|
| 心身の状態 | 睡眠、食欲、涙、動悸、出勤困難、体調不良 |
| 職場の原因 | 上司、人間関係、仕事量、仕事内容、評価制度 |
| 継続可能性 | 異動、相談、休職、業務調整で改善可能か |
| 生活面 | 貯金、家賃、実家、失業保険、次の収入 |
| 次の選択肢 | 転職、休職、異動、相談窓口、専門家相談 |
| 証拠 | メール、チャット、録音、日記、勤務記録、診断書など |

## 4. 職場ストレスとメンタルヘルスに関する専門知識

### 4-1. 強いストレスを感じる労働者の割合

令和6年の労働安全衛生調査では、仕事や職業生活に関して強いストレスを感じる事柄がある労働者は68.3％。

主なストレス内容には、以下が含まれる。

- 仕事の量
- 仕事の失敗
- 責任の発生
- 仕事の質
- 対人関係
- 雇用の安定性

### 4-2. 職場ストレスの分類

職場ストレスは、以下のように分類できる。

| 分類 | 内容 |
|---|---|
| 業務量ストレス | 仕事が多すぎる、期限が厳しい、残業が多い |
| 業務質ストレス | 難易度が高い、責任が重い、失敗が許されない |
| 対人ストレス | 上司、同僚、顧客との関係で消耗する |
| 評価ストレス | 評価基準が曖昧、怒られる基準が分からない |
| 役割ストレス | 何をどこまでやるべきか不明確 |
| 将来不安 | 給与、雇用、キャリア、スキルへの不安 |

### 4-3. 上司ストレスの特徴

上司との関係によるストレスは、他のストレスと比べて逃げ場が少ない。

理由は以下。

- 毎日関わる可能性が高い
- 評価権限を持っている
- 質問・報告・相談が必要
- ミスの判断者になりやすい
- 異動や退職をしない限り関係が続きやすい
- 周囲に相談しにくい

### 4-4. 限界サインとして注意すべき状態

以下の状態が継続する場合、単なる仕事の疲れではなく、相談や休養が必要な可能性がある。

- 朝起きると涙が出る
- 出勤前に吐き気がする
- 会社の最寄駅に近づくと動悸がする
- チャット通知や電話音で体が固まる
- 上司の声を聞くだけで息苦しい
- 眠れない
- 食欲が落ちる
- 休日も仕事のことが頭から離れない
- 好きだったことに興味がなくなる
- 自分が全部悪いと思い込む
- 消えたいと思う

### 4-5. こころの耳

厚生労働省が委託事業として運営する「こころの耳」は、職場のメンタルヘルスに関する情報提供、セルフケア、相談窓口を提供している。

主な内容は以下。

- ストレスセルフチェック
- 相談窓口
- 職場のメンタルヘルス情報
- 働く人向けのセルフケア情報
- 家族向け情報
- 事業者向け情報

### 4-6. 労働条件相談ほっとライン

「労働条件相談ほっとライン」は、厚生労働省の委託事業として運営されている無料相談窓口。

対象となる相談例は以下。

- 違法な時間外労働
- 過重労働による健康障害
- 賃金不払残業
- 労働基準関係法令に関する問題
- 労働条件に関する疑問

匿名で相談できる点が特徴。

## 5. 転職理由に関する統計知識

### 5-1. 雇用動向調査における転職理由

令和6年の雇用動向調査では、女性の転職入職者が前職を辞めた理由について、「その他の個人的理由」を除くと、以下が上位に入っている。

| 理由 | 女性の割合 |
|---|---|
| 労働時間、休日等の労働条件が悪かった | 12.8％ |
| 職場の人間関係が好ましくなかった | 11.7％ |

このことから、人間関係は女性の転職理由として重要な要素である。

### 5-2. 人間関係による退職の整理

人間関係で退職を考える場合、以下の3段階で整理すると客観化しやすい。

| 段階 | 内容 |
|---|---|
| 表面 | 上司が怖い、会いたくない、質問しづらい |
| 中間 | 報連相ができない、ミスが増える、萎縮する |
| 根本 | 安心して働ける環境ではない、就業継続が難しい |

### 5-3. 人間関係による退職が軽視されやすい理由

人間関係による退職は、以下の理由で軽視されやすい。

- 数値で説明しにくい
- 周囲から「どこにでも嫌な人はいる」と言われやすい
- 本人が自分の弱さだと思いやすい
- 上司が外面では良い人に見えることがある
- 業務内容そのものに不満がない場合、説明が難しい
- パワハラとまでは言い切れないケースがある

### 5-4. 人間関係による退職の専門的な見方

人間関係による退職は、単なる好き嫌いではなく、以下の観点で考える必要がある。

- 業務遂行に必要な相談ができるか
- 心理的安全性があるか
- ミスを報告できるか
- 指導が改善につながっているか
- 評価基準が明確か
- 特定の人の機嫌に業務が左右されていないか
- 長期的に働き続けられるか

## 6. 職場いじめ・ハラスメントと離職意向に関する研究知識

### 6-1. 職場いじめと離職意向

2025年にBMC Public Healthで公開されたシステマティックレビュー・メタ分析では、職場いじめを経験することは、従業員の離職意向の増加と正の関連があると報告されている。

対象は27研究で、横断研究・前向き研究の両方が含まれる。

### 6-2. 職場の無礼・軽視と離職意向

2021年のメタ分析では、職場でのインシビリティ、つまり無礼・失礼・軽視されるような行動の認知と、離職意向には正の関連があると示されている。

ここで重要なのは、明確な暴言や暴力だけではなく、日常的な軽視も離職意向に関係しうるという点。

### 6-3. ワークエンゲージメントとの関係

職場いじめと離職意向の関係について、ワークエンゲージメントが媒介する可能性を検討した研究では、仕事関連・個人関連のいじめ認知が、活力や献身の低さと関連し、それが高い離職意向と関連することが示されている。

### 6-4. 研究知見から言えること

研究知見を踏まえると、以下の整理ができる。

- 職場でのいじめやハラスメントは、離職意向と関連する
- 明確なパワハラだけでなく、日常的な無礼や軽視も影響しうる
- 上司との関係が悪いと、仕事そのものへの活力が下がる可能性がある
- 「仕事が嫌い」ではなく「人間関係で仕事への意欲が削られている」ケースがある
- 退職意向は本人の根性不足ではなく、環境要因の影響を受ける

## 7. 退職理由・面接での説明に関する専門知識

### 7-1. 退職理由と転職理由の違い

退職理由と転職理由は分けて考える必要がある。

| 項目 | 内容 |
|---|---|
| 退職理由 | 前職を辞めたい、または辞めた理由 |
| 転職理由 | 次の職場で実現したいこと |
| 志望動機 | その会社を選ぶ理由 |

人間関係で辞めた場合でも、面接では「前職の不満」だけで終わらせず、次の環境で何を大切にしたいかまで整理する必要がある。

### 7-2. 人間関係の退職理由を伝える時の注意点

リクルートエージェントなどの転職支援情報では、人間関係による退職理由について、特定個人への不満として伝えるよりも、社風や働き方のミスマッチとして伝える方が客観性が増すとされている。

面接官が見ているのは、主に以下。

- 入社後に同じ理由で辞めないか
- 他責傾向が強すぎないか
- 前職の不満をそのまま持ち込まないか
- 自分なりに改善行動を取ったか
- 次の職場に求める条件が明確か

### 7-3. 人間関係による退職理由の変換構造

| 本音 | 客観化 | 次の職場で求めること |
|---|---|---|
| 上司が怖かった | 相談・確認がしづらい環境だった | 報連相しながら正確に進められる環境 |
| 怒鳴られるのがつらかった | 感情的な指導が多かった | 改善点を具体的に確認できる環境 |
| 質問できなかった | 不明点を早めに解消しづらかった | 相談しやすい体制 |
| 人間関係で疲れた | 連携の取り方にミスマッチがあった | チームで落ち着いて働ける環境 |
| 放置された | 教育体制が不十分だった | 入社後のフォロー体制がある環境 |
| 仕事を押し付けられた | 役割範囲が曖昧だった | 業務範囲が明確な環境 |

### 7-4. 退職理由で避けたい伝え方

| 避けたい表現 | 理由 |
|---|---|
| 上司が嫌いでした | 感情的な不満に聞こえやすい |
| 人間関係が最悪でした | 他責に聞こえやすい |
| パワハラされました | 詳細確認が必要になり、話が重くなりやすい |
| 会社が合いませんでした | 抽象的で再現性が見えない |
| とにかく辞めたかったです | 計画性に不安を持たれやすい |

### 7-5. 退職理由で必要な要素

退職理由には、以下の要素があると説明しやすい。

- 前職で感じた課題
- 自分なりに取った行動
- 改善が難しかった理由
- 次の職場で大切にしたいこと
- 志望先との接点

## 8. 第二新卒女性の転職に関する専門知識

- ポテンシャルを見られやすい
- 即戦力よりも適応力が重視されることがある
- 退職理由の説明が重要になりやすい
- 次の職場で長く働けるかを見られやすい

面接では、以下が確認されやすい。

- 早期離職の理由
- 同じ理由でまた辞めないか
- 人間関係をどう捉えているか
- 相談や改善行動を取ったか
- ストレス耐性
- 自社の環境との相性
- 希望条件の現実性

### 8-3. 第二新卒が退職理由を整理する時の軸

| 人間関係 | 誰との関係が負担だったのか |
| 教育体制 | 教えてもらえる環境があったか |
| 相談体制 | 困った時に相談できたか |
| 労働条件 | 残業、休日、給与に問題があったか |

## 9. 一般事務に関する職業知識

### 9-1. 一般事務の仕事内容

厚生労働省の職業情報提供サイト job tag によると、一般事務は、特定分野の専門事務ではなく、さまざまな定型的な事務作業を行う仕事。

- メール応対
- 電話応対
- 伝票作成
- 台帳管理
- データ入力
- 書類整理
- 社内届出書類の管理
- 備品管理
- 来客対応

### 9-2. 一般事務で起こりやすい負担

一般事務は「楽そう」と見られることがあるが、実際には以下の負担がある。

- 正確性を求められる
- 細かいミスが目立ちやすい
- 社内調整が多い
- 依頼者が複数いる
- 優先順位が曖昧になりやすい
- 見えない雑務が多い
- 仕事の成果が評価されにくい
- 上司の指示が曖昧だと混乱しやすい

### 9-3. 一般事務で上司リスクが高まる状況

- 指示が曖昧
- ミスだけ強く責められる
- 確認しづらい
- マニュアルがない
- 教える人が決まっていない
- 優先順位を相談できない
- 複数人から同時に依頼される
- 評価基準が不明確

## 10. 営業事務に関する職業知識

### 10-1. 営業事務の仕事内容

job tag によると、営業事務は、営業担当の指示を受けて、資料・見積書を作成したり、クライアント対応や管理業務を行うなど、営業活動をサポートする仕事。

主な業務には以下が含まれる。

- 見積書作成
- 納品書作成
- 請求書作成
- 受発注処理
- 顧客からの電話・メール対応
- 営業資料作成
- 書類の受発送
- 在庫確認
- 納期調整
- 営業担当との連携

### 10-2. 営業事務で起こりやすい負担

営業事務は、営業担当・顧客・社内部署の間に立つことが多い。

そのため、以下の負担が発生しやすい。

- 営業担当から急ぎの依頼が来る
- 顧客から問い合わせを受ける
- 納期や金額のミスが大きな問題になりやすい
- 営業担当の指示が曖昧なまま処理を求められる
- 板挟みになりやすい
- 責任範囲が曖昧になりやすい
- 感謝されにくいが、ミスは目立ちやすい

### 10-3. 営業事務で確認すべき職場条件

| 項目 | 確認内容 |
|---|---|
| 役割範囲 | 営業担当と事務の業務分担が明確か |
| 判断権限 | どこまで自分で判断するのか |
| 顧客対応 | 一次対応のみか、判断まで求められるか |
| 教育体制 | 受発注や請求処理のマニュアルがあるか |
| 繁忙期 | 月末月初、決算期の忙しさ |
| 連携方法 | 営業担当との連絡手段と頻度 |
| ミス対応 | 個人責任ではなく仕組みで防ぐ体制があるか |

## 11. カスタマーサポート・コールセンターに関する職業知識

### 11-1. カスタマーサポートの仕事内容

カスタマーサポートやコールセンター業務は、顧客からの問い合わせに対応する仕事。

主な業務には以下が含まれる。

- 電話対応
- メール対応
- チャット対応
- 問い合わせ内容の記録
- クレーム対応
- 商品・サービスの説明
- 担当部署への連携
- 対応履歴の入力
- FAQやマニュアルに沿った案内

### 11-2. カスタマーサポートで起こりやすい負担

- 顧客から感情をぶつけられる
- クレーム対応がある
- 対応件数が多い
- 常に正確な説明が求められる
- 対応時間を管理される
- 録音やモニタリングがある
- 自分では解決できない問題を受ける
- 上司にエスカレーションしづらいと負担が増える

### 11-3. カスタマーサポートにおける上司リスク

カスタマーサポートでは、顧客対応そのものよりも、対応後の上司のフォロー体制が重要。

上司リスクが高い環境には、以下の特徴がある。

- クレーム後にフォローがない
- 顧客対応の責任を個人に押し付ける
- 判断基準が曖昧
- エスカレーションしづらい
- 対応件数だけで評価される
- 感情労働への理解がない
- ミスの共有が責める場になっている

### 11-4. カスタマーサポートで確認すべき職場条件

| 項目 | 確認内容 |
|---|---|
| 対応範囲 | どこまで一次対応するのか |
| エスカレーション | 判断に迷った時の相談先が明確か |
| クレーム対応 | 一人で抱え込まない体制があるか |
| 評価基準 | 件数だけでなく品質も評価されるか |
| 研修 | ロープレ、FAQ、マニュアルがあるか |
| フォロー | 対応後の振り返りや面談があるか |

## 12. 上司リスクに関する専門知識

### 12-1. 上司リスクとは

上司リスクとは、仕事内容や条件は悪くないにもかかわらず、直属上司の関わり方によって働き続けることが難しくなるリスク。

以下の要素が含まれる。

- 指示の曖昧さ
- 感情的な指導
- 相談しづらさ
- 評価基準の不明確さ
- 情報共有の偏り
- 責任の押し付け
- ミスへの過剰反応
- 部下の心理的安全性への無関心

### 12-2. 上司リスクが高い職場の特徴

| 項目 | 特徴 |
|---|---|
| 指示 | 抽象的、後出し、頻繁に変わる |
| 相談 | 質問すると不機嫌になる |
| 評価 | 基準が見えず、機嫌に左右される |
| ミス対応 | 原因分析より叱責が中心 |
| 情報共有 | 一部の人にだけ情報が渡る |
| 教育 | 見て覚えろ、聞かないと教えない |
| 責任 | 判断権限はないのに責任だけ重い |
| 雰囲気 | 上司の機嫌で職場の空気が変わる |

### 12-3. 上司リスクが低い職場の特徴

| 項目 | 特徴 |
|---|---|
| 指示 | 目的・期限・優先順位が明確 |
| 相談 | 質問しやすい時間や手段がある |
| 評価 | 評価基準が説明される |
| ミス対応 | 再発防止を仕組みで考える |
| 情報共有 | 必要な情報が適切に共有される |
| 教育 | 研修、マニュアル、担当者がある |
| 責任 | 権限と責任の範囲が一致している |
| 雰囲気 | 特定の人の機嫌に左右されにくい |

### 12-4. 求人票で見る上司リスク

| 求人票の表現 | 注意点 |
|---|---|
| アットホームな職場 | 実態として距離が近すぎる可能性もある |
| 風通しが良い | 相談しやすい仕組みがあるか確認が必要 |
| 若手活躍 | 教育体制があるか、放置ではないか確認が必要 |
| 裁量が大きい | 未経験に責任を押し付ける環境ではないか確認が必要 |
| 成長できる環境 | 具体的に何をどう学べるのか確認が必要 |
| OJTあり | 誰が、どの期間、どの範囲で教えるのか確認が必要 |
| 幅広くお任せ | 業務範囲が曖昧な可能性がある |

## 13. 心理的安全性に関する専門知識

### 13-1. 心理的安全性とは

心理的安全性とは、チームの中で自分の考えや疑問、ミス、不安を表明しても、不利益や拒絶を受けにくいと感じられる状態。

職場においては、以下の行動ができるかに関係する。

- 分からないことを質問できる
- ミスを早めに報告できる
- 違和感を相談できる
- 助けを求められる
- 自分の意見を言える
- 失敗から学べる

### 13-2. 心理的安全性が低い職場

- 質問すると怒られる
- ミスを隠したくなる
- 分からないと言えない
- 報告が遅れる
- 上司の機嫌を優先してしまう
- 誰に相談すればいいか分からない
- 沈黙が安全策になる

### 13-3. 心理的安全性が低いと起こること

- ミスが早期に共有されない
- 業務改善が進まない
- 若手が萎縮する
- 報連相が減る
- 離職意向が高まりやすい
- 心身の不調につながりやすい
- 仕事そのものへの意欲が下がる

## 14. 退職判断に必要なチェック項目

### 14-1. 心身のチェック

| 項目 | 確認 |
|---|---|

| 思考 | 自分が全部悪いと思い込む |
| 行動 | 求人を見る気力も出ない |

### 14-2. 職場環境のチェック

| 項目 | 確認 |
|---|---|
| 相談 | 困った時に相談できる人がいるか |
| 指示 | 業務指示が明確か |
| 評価 | 評価基準が分かるか |

- 異動を相談する
- 業務量の調整を依頼する
- 転職活動を始める
- 家族や友人に状況を共有する

## 18. アフィリエイト・広告表記に関する専門知識

### 18-1. ステルスマーケティング規制

消費者庁は、広告であるにもかかわらず広告であることを隠す表示をステルスマーケティングとして整理している。

令和5年10月1日から、ステルスマーケティングは景品表示法上の不当表示として規制対象になっている。

広告には、企業がインフルエンサー等の第三者に依頼・指示して行う表示も含まれる。

### 18-2. アフィリエイトで注意すべき点

- 広告であることを明示する
- PR、広告など読者が分かる表記を入れる
- 成果条件を誤認させない
- 転職成功を保証しない
- 内定を保証しない
- 年収アップを保証しない
- 無料相談の内容を誇張しない
- 読者の不安を過度に煽らない
- 医療・法律・労働問題について断定しない

### 18-3. 転職アフィリエイトで特に注意すべき表現

| 注意表現 | 理由 |
|---|---|
| 必ず転職できる | 成果保証に見える |
| 年収が上がる | 個人差が大きい |
| 相談すれば解決 | 過度な期待を与える |
| すぐ辞めて大丈夫 | 生活リスクを軽視している |
| 会社が悪い | 法的断定に近づく可能性 |
| それは違法 | 個別判断が必要 |
| 絶対パワハラ | 個別判断が必要 |

## 25. ブラック企業・危険な職場選びに関する専門知識

### 25-1. ブラック企業という言葉の扱い

「ブラック企業」は法律上の明確な定義がある用語ではない。

発信では、感情的に「ブラック企業」と断定するよりも、以下のような客観的な要素に分解して扱う方が信頼性が高い。

- 労働時間が長すぎる
- 休日が少ない
- 残業代が適切に支払われない
- 離職率が高い
- 求人票と実態が違う
- 教育体制がない
- ハラスメントが放置されている
- 相談窓口が機能していない
- 上司の感情で職場が動いている
- 評価基準が不透明
- 退職を言い出しにくい雰囲気がある

### 25-2. ブラック企業を見極める時の基本視点

ブラック企業かどうかを見る時は、会社の印象ではなく、以下の観点で整理する。

| 観点 | 確認する内容 |
|---|---|
| 労働時間 | 残業時間、繁忙期、休日出勤の有無 |
| 休日 | 年間休日、有給取得率、休みやすさ |
| 給与 | 基本給、固定残業代、手当、賞与 |
| 雇用条件 | 正社員、契約社員、試用期間、雇用期間 |
| 業務内容 | 求人票と実際の仕事が一致しているか |
| 教育体制 | OJT担当、研修、マニュアル、相談先 |
| 評価制度 | 何を基準に評価されるか |
| 離職率 | 人が定着しているか |
| 相談体制 | 人事、産業医、相談窓口があるか |
| 管理職 | 上司の指導スタイル、チーム運営 |

## 26. 求人票で注意すべき表現

### 26-1. 抽象的なポジティブ表現

| 表現 | 確認すべきこと |
|---|---|
| アットホームな職場 | 距離感が近すぎないか、私生活に踏み込まれないか |
| 風通しが良い | 実際に相談できる仕組みがあるか |

## 28. 令和式ブラック企業の特徴

### 28-1. 昔ながらのブラック企業と令和式ブラック企業

昔ながらのブラック企業は、長時間労働・休日出勤・怒鳴る上司など、分かりやすい問題が目立ちやすい。

一方で、令和式ブラック企業は、表面上はきれいに見えるが、実態として働く人が削られる構造を持っている場合がある。

### 28-2. 令和式ブラック企業の特徴

| 特徴 | 内容 |
|---|---|
| 表向きはホワイト風 | SNSや採用ページでは雰囲気が良く見える |
| 言葉がきれい | 成長、挑戦、裁量、仲間などの表現が多い |
| 責任が曖昧 | 若手にも大きな責任を持たせるが権限は少ない |
| 教育が薄い | OJTという名の放置がある |
| 相談しづらい | 困っても聞ける人がいない |
| 心理的に削られる | 怒鳴られなくても、常に緊張状態になる |
| 評価が不透明 | 何をすれば評価されるか分からない |
| 退職しにくい空気 | 辞める人を裏切り者のように扱う |

### 28-3. 見た目が良い会社ほど確認すべきこと

採用ページやSNSで雰囲気が良く見える会社ほど、以下を確認する。

- 入社後の教育体制
- 直属上司との関わり方
- 平均残業時間
- 有給取得率
- 離職率
- 評価制度

- ミスが起きた時の対応

## 29. 職場選びにおける「上司リスク」と求人票の関係

### 29-1. 求人票だけでは上司リスクは見えにくい

上司リスクは、求人票だけでは分かりにくい。

理由は以下。

- 求人票には直属上司の性格が書かれていない
- チーム内の雰囲気は求人票に出にくい
- 相談しやすさは数値化されにくい
- ミス対応の文化は面接で聞かないと分かりにくい
- 教育体制が「OJT」とだけ書かれていることが多い

### 29-2. 上司リスクを求人票から推測する観点

| 求人票の項目 | 上司リスクの見方 |
|---|---|
| 仕事内容 | 業務範囲が具体的か |
| 教育体制 | 誰がどう教えるか明記されているか |
| チーム構成 | 所属部署や人数が分かるか |
| 評価制度 | 評価基準や面談頻度があるか |
| 残業時間 | 業務量が管理されているか |
| 求める人物像 | 忍耐力や素直さばかり強調されていないか |
| キャリアパス | 入社後の成長ルートが具体的か |

### 29-3. 面接で確認すべき上司リスク

| 確認項目 | 見るポイント |
|---|---|
| 直属上司 | どのような立場の人が上司になるか |

## 30. 若手・第二新卒が注意すべき会社の特徴

### 30-1. 第二新卒が削られやすい職場

第二新卒は、社会人経験が浅いため、以下の職場で削られやすい。

- 教育体制がない
- 質問しづらい
- 失敗を責められる
- 業務範囲が曖昧
- 相談先がない
- 同世代が少ない
- 直属上司との距離が近すぎる
- 評価基準が分からない
- 早期に即戦力扱いされる
- 「若いからできるよね」と負荷をかけられる

### 30-2. 第二新卒が求人票で確認すべきこと

| 項目 | 確認内容 |
|---|---|
| 未経験歓迎 | 教育体制があるか |
| 第二新卒歓迎 | 過去に第二新卒を採用して定着しているか |
| OJT | 担当者・期間・内容が明確か |
| 研修制度 | 入社後研修、職種別研修があるか |
| チーム体制 | 一人で抱え込まない構造か |
| 評価制度 | 何を基準に評価されるか |
| キャリアパス | 事務職・営業事務としてどう成長できるか |
| 平均年齢 | 若手が馴染みやすいか |
| 離職率 | 早期離職が多くないか |
