## 25. ブラック企業・危険な職場選びに関する専門知識

### 25-1. ブラック企業という言葉の扱い

「ブラック企業」は法律上の明確な定義がある用語ではない。

発信では、感情的に「ブラック企業」と断定するよりも、以下のような客観的な要素に分解して扱う方が信頼性が高い。

- 労働時間が長すぎる
- 休日が少ない
- 残業代が適切に支払われない
- 離職率が高い
- 求人票と実態が違う
- 教育体制がない
- ハラスメントが放置されている
- 相談窓口が機能していない
- 上司の感情で職場が動いている
- 評価基準が不透明
- 退職を言い出しにくい雰囲気がある

### 25-2. ブラック企業を見極める時の基本視点

ブラック企業かどうかを見る時は、会社の印象ではなく、以下の観点で整理する。

| 観点 | 確認する内容 |
|---|---|
| 労働時間 | 残業時間、繁忙期、休日出勤の有無 |
| 休日 | 年間休日、有給取得率、休みやすさ |
| 給与 | 基本給、固定残業代、手当、賞与 |
| 雇用条件 | 正社員、契約社員、試用期間、雇用期間 |
| 業務内容 | 求人票と実際の仕事が一致しているか |
| 教育体制 | OJT担当、研修、マニュアル、相談先 |
| 評価制度 | 何を基準に評価されるか |
| 離職率 | 人が定着しているか |
| 相談体制 | 人事、産業医、相談窓口があるか |
| 管理職 | 上司の指導スタイル、チーム運営 |

## 26. 求人票で注意すべき表現

### 26-1. 抽象的なポジティブ表現

求人票では、以下のような抽象的な表現に注意する。

| 表現 | 確認すべきこと |
|---|---|
| アットホームな職場 | 距離感が近すぎないか、私生活に踏み込まれないか |
| 風通しが良い | 実際に相談できる仕組みがあるか |
| 若手活躍 | 教育なしで若手に責任を負わせていないか |
| 成長できる環境 | 何を、誰から、どのように学べるのか |
| 裁量が大きい | 権限と責任のバランスが取れているか |
| やりがいがある | 労働条件の悪さをやりがいで隠していないか |
| 幅広い業務をお任せ | 業務範囲が曖昧ではないか |
| OJTあり | 誰が、何ヶ月、どの範囲まで教えるのか |
| 未経験歓迎 | 教育体制が本当にあるか |
| 人柄重視 | 評価基準が曖昧ではないか |

### 26-2. 固定残業代に関する注意点

求人票に固定残業代がある場合、以下を確認する必要がある。

- 固定残業代が何時間分なのか
- 固定残業時間を超えた分は別途支給されるのか
- 基本給と固定残業代が分けて記載されているか
- 実際の平均残業時間は何時間か
- 固定残業代込みの給与を高く見せていないか

### 26-3. 年間休日に関する注意点

年間休日は、働き続けやすさに直結する。

確認すべき項目は以下。

- 年間休日数
- 完全週休2日制か、週休2日制か
- 土日祝休みか
- 祝日が休みに含まれるか
- 夏季休暇・年末年始休暇があるか
- 有給休暇が取りやすいか
- 繁忙期に休日出勤があるか

#### 完全週休2日制と週休2日制の違い

| 表現 | 意味 |
|---|---|
| 完全週休2日制 | 毎週必ず2日の休みがある |
| 週休2日制 | 月に1回以上、週2日の休みがある。毎週2日休みとは限らない |

## 27. 求人票と実態のズレに関する専門知識

### 27-1. 求人票でズレが起きやすい項目

求人票と実態でズレが起きやすいのは、以下。

- 仕事内容
- 勤務地
- 残業時間
- 休日
- 給与
- 固定残業代
- 雇用形態
- 試用期間中の条件
- 配属部署
- 教育体制
- 評価制度
- 転勤の有無

### 27-2. 求人票を見る時の基本原則

求人票は、会社が求職者に見せる「募集条件」であり、職場の実態すべてを表すものではない。

そのため、求人票を見る時は以下の3段階で確認する。

1. 求人票に何が書かれているか
2. 書かれていないことは何か
3. 面接で確認すべきことは何か

### 27-3. 書かれていないことに注意する

求人票では、書かれていること以上に、書かれていないことも重要。

| 書かれていない項目 | 確認すべき理由 |
|---|---|
| 平均残業時間 | 実際の働き方が見えない |
| 教育体制 | 入社後に放置される可能性がある |
| 配属部署 | 人間関係や上司が見えない |
| チーム人数 | 業務負担が見えない |
| 退職者の有無 | 定着率が見えない |
| 評価基準 | 何で評価されるか分からない |
| 繁忙期 | 忙しさの波が見えない |
| 相談体制 | 困った時に頼れる相手が見えない |

## 28. 令和式ブラック企業の特徴

### 28-1. 昔ながらのブラック企業と令和式ブラック企業

昔ながらのブラック企業は、長時間労働・休日出勤・怒鳴る上司など、分かりやすい問題が目立ちやすい。

一方で、令和式ブラック企業は、表面上はきれいに見えるが、実態として働く人が削られる構造を持っている場合がある。

### 28-2. 令和式ブラック企業の特徴

| 特徴 | 内容 |
|---|---|
| 表向きはホワイト風 | SNSや採用ページでは雰囲気が良く見える |
| 言葉がきれい | 成長、挑戦、裁量、仲間などの表現が多い |
| 責任が曖昧 | 若手にも大きな責任を持たせるが権限は少ない |
| 教育が薄い | OJTという名の放置がある |
| 相談しづらい | 困っても聞ける人がいない |
| 心理的に削られる | 怒鳴られなくても、常に緊張状態になる |
| 評価が不透明 | 何をすれば評価されるか分からない |
| 退職しにくい空気 | 辞める人を裏切り者のように扱う |

### 28-3. 見た目が良い会社ほど確認すべきこと

採用ページやSNSで雰囲気が良く見える会社ほど、以下を確認する。

- 入社後の教育体制
- 直属上司との関わり方
- 平均残業時間
- 有給取得率
- 離職率
- 評価制度
- 若手の業務範囲
- 相談窓口
- メンタル不調時の対応
- ミスが起きた時の対応

## 29. 職場選びにおける「上司リスク」と求人票の関係

### 29-1. 求人票だけでは上司リスクは見えにくい

上司リスクは、求人票だけでは分かりにくい。

理由は以下。

- 求人票には直属上司の性格が書かれていない
- チーム内の雰囲気は求人票に出にくい
- 相談しやすさは数値化されにくい
- ミス対応の文化は面接で聞かないと分かりにくい
- 教育体制が「OJT」とだけ書かれていることが多い

### 29-2. 上司リスクを求人票から推測する観点

| 求人票の項目 | 上司リスクの見方 |
|---|---|
| 仕事内容 | 業務範囲が具体的か |
| 教育体制 | 誰がどう教えるか明記されているか |
| チーム構成 | 所属部署や人数が分かるか |
| 評価制度 | 評価基準や面談頻度があるか |
| 残業時間 | 業務量が管理されているか |
| 求める人物像 | 忍耐力や素直さばかり強調されていないか |
| キャリアパス | 入社後の成長ルートが具体的か |

### 29-3. 面接で確認すべき上司リスク

| 確認項目 | 見るポイント |
|---|---|
| 直属上司 | どのような立場の人が上司になるか |
| 相談方法 | 分からない時に誰へ相談するか |
| 研修期間 | 入社後いつまでフォローがあるか |
| ミス対応 | ミスを責めるのか、仕組みで改善するのか |
| チーム人数 | 1人あたりの業務負担 |
| 前任者 | 退職・異動理由 |
| 繁忙期 | 忙しい時期の残業や雰囲気 |

## 30. 若手・第二新卒が注意すべき会社の特徴

### 30-1. 第二新卒が削られやすい職場

第二新卒は、社会人経験が浅いため、以下の職場で削られやすい。

- 教育体制がない
- 質問しづらい
- 失敗を責められる
- 業務範囲が曖昧
- 相談先がない
- 同世代が少ない
- 直属上司との距離が近すぎる
- 評価基準が分からない
- 早期に即戦力扱いされる
- 「若いからできるよね」と負荷をかけられる

### 30-2. 第二新卒が求人票で確認すべきこと

| 項目 | 確認内容 |
|---|---|
| 未経験歓迎 | 教育体制があるか |
| 第二新卒歓迎 | 過去に第二新卒を採用して定着しているか |
| OJT | 担当者・期間・内容が明確か |
| 研修制度 | 入社後研修、職種別研修があるか |
| チーム体制 | 一人で抱え込まない構造か |
| 評価制度 | 何を基準に評価されるか |
| キャリアパス | 事務職・営業事務としてどう成長できるか |
| 平均年齢 | 若手が馴染みやすいか |
| 離職率 | 早期離職が多くないか |
