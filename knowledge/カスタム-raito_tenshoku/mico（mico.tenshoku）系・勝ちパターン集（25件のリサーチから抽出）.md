# mico（mico.tenshoku）系・勝ちパターン集（25件のリサーチから抽出）

**目的**: 1投稿目（フック）と全体構成の精度を最大化するためのテンプレ集。
2026年2/26〜4/19に @mico.tenshoku で平均1,024いいねを獲得した25投稿（102〜5,749）を構造分析し、raito_tenshoku 専用に最適化したもの。

---

## 使い方の原則

- 1バッチの投稿のうち、ここの型は2本以上に同じ型を使わないこと（既存rules準拠）
- パターンの「{{スロット}}」部分はコンセプトシートのテーマ・ペルソナに沿って必ず固有化する
- 実例の文言をそのままコピーするのではなく、構造を借りて新しい一文を作る
- 「人事として」「採用担当として」は使わない。raito_tenshoku のペルソナは転職経験者（当事者）なので「転職して気づいた」「3社で働いて分かった」「実際に上司が原因で辞めた経験から」等の当事者ラベルを使うこと
- 数字（いいね数）は内部参考情報。投稿本文に含めない
- ツリー前提（2〜3投稿）の型が多い。1投稿目で詰めすぎず、本編は2〜3投稿目に分割する（4投稿以上禁止）

## 【型1】短文人物像連打→「逆」匂わせ型 ★★★

### 構造
```
{{導入の短い1文（〜辞めた／〜いなくなった）}}
{{人物像を表す名詞句1}}。
{{人物像を表す名詞句2}}。
{{人物像を表す名詞句3}}。
{{(任意)セリフ引用付きの人物像4}}
{{構造の反転を予告する1文（こういう人から、いなくなる）}}
{{「逆」を匂わせる1文（残るのは、なぜか逆。）}}
```

### スロット
- **導入の短い1文**: 「また一人、辞めた。」「また、あの人が辞めた。」「また一人、辞めました。」 ← 句点で切る短文
- **人物像を表す名詞句（3〜4個）**: 一行で1人物像。「現場を回してた人。」「誰よりも気を配ってた人。」「一番頼りにされてた人。」「誰よりも仕事してた人。」「一番話しやすかった人。」 ← 全て「〜人。」で揃える
- **セリフ引用付きの人物像**: 「『この人いれば大丈夫』ってみんな思ってた人。」 ← 1つあるとリズムが変わる
- **構造の反転を予告する1文**: 「こういう人から、いなくなる。」「いい人ほど先にいなくなる。」
- **「逆」を匂わせる1文**: 「残るのは、なぜか逆。」「なんでこの人は残るんだろうって人はずっといる。」 ← 次投稿への引きとして必ず半端に切る

### 実例（元アカウントの構造から生成）
- また一人、辞めた。現場を回してた人。誰よりも気を配ってた人。一番頼りにされてた人。「この人いれば大丈夫」ってみんな思ってた人。こういう人から、いなくなる。残るのは、なぜか逆。
- 職場って不思議で、「この人がいてくれると助かる」って人ほど先にいなくなる。逆に、なんでこの人は残るんだろうって人はずっといる。これ、たまたまじゃないです。

### 使うべきテーマ
職場の不公平構造、頑張る人だけが消耗する話、退職者の特徴。読者の「うちもそう」を一発で引き出すので、シリーズの起点に置くと反応が爆発しやすい。

### 注意
- 名詞句は全て「〜人。」で語尾を揃える。リズムが命の型なので崩れると一気に弱くなる
- 「逆」を匂わせて半端切りで次投稿へ繋ぐのが鉄板。1投稿で完結させない
- 特定の同僚が特定できる書き方は避ける（「お局さん」等の強い語は使わない）
- 本編（2投稿目）では「やらない人／責任取らない人／声だけ大きい人」との対比を入れる。inputベースで決めておく

## 【型2】揺れの二項対立→「経験ありませんか」型 ★★★

### 構造
```
「{{ネガティブな心の声}}」って思う日と、
「{{相殺するポジティブ寄りの心の声}}」って思う日。
この2つを行ったり来たりして、
気づいたら{{時間経過の表現}}過ぎていた。
そんな経験、ありませんか。
```

### スロット
- **ネガティブな心の声**: 短く強く。「もう無理。辞めたい」「このままだと壊れる」 ← 句点入りでもOK
- **相殺するポジティブ寄りの心の声**: 自分を納得させるロジック。「でも条件は悪くないし、もう少し頑張れるかも」「でもブラックってほどじゃないし」 ← 「でも」始まりが基本
- **時間経過の表現**: 「何ヶ月も」「半年」「気づいたら1年」 ← 具体的すぎず曖昧に
- **問いかけの締め**: 「そんな経験、ありませんか。」「これ、私だけじゃないと思う。」 ← 句点で完結、絵文字は不要

### 実例（元アカウントの構造から生成）
- 「もう無理。辞めたい」って思う日と、「でも条件は悪くないし、もう少し頑張れるかも」って思う日。この2つを行ったり来たりして、気づいたら何ヶ月も過ぎていた。そんな経験、ありませんか。
- その状態、いちばん消耗します。「もう無理。辞めたい」って思う日と、「でもまだ頑張れるかも」って思う日。この2つを行ったり来たりして、気づいたら何ヶ月も経ってる。

### 使うべきテーマ
辞めるか続けるかで揺れている人、決断できない自分を責めている人。本編は「揺れている時間そのものが消耗」「動けない理由は気持ちじゃなく情報不足」の流れで。CTAはUZUZ無料相談へ自然に繋げやすい型。

### 注意
- 心の声は「」で囲む。地の文に混ぜると揺れの可視化が弱まる
- 元アカウントはこのフックを5回投稿してすべて100いいね以上 ＝ 最も再現性の高い型。raito_tenshoku でも定番化させてよい
- 本編で「真面目な人ほど悩み続けます」「完全に辞めると決めた人より、揺れている人の方が消耗する」と読者を肯定する流れを必ず入れる

## 【型3】当事者ポジション断定→否定列挙→真因提示型 ★★★

### 構造
```
{{当事者ポジションの宣言}}。
{{核となる主張を断定で1文}}。
{{否定列挙：〇〇でもない、△△でもない、××でもない}}。
「{{真因を「」で1文}}」と感じた瞬間です。
```

### スロット
- **当事者ポジションの宣言**: raito_tenshoku の実体験ベースで宣言する。「3社で働いて気づきました」「転職して初めて分かりました」「実際に上司が原因で辞めた経験から言います」「2回転職して分かったのは」など。「人事として」「採用担当として」は使わない
- **核となる主張**: 「人が辞める理由は、条件ではありません」「転職活動が進まない理由は、スキルじゃない」など、短く断定
- **否定列挙**: 表面的な原因を3つ並べて否定。「給料でも、労働時間でもない。」「経歴でもスキルでもありません。」 ← リズムよく3連（4つ以上は説教臭くなる）
- **真因の「」セリフ**: 心の中で起きていることを引用形で出す。「『この会社にいても自分は大事にされない』と感じた瞬間です」

### 実例（raito_tenshoku用に生成）
- 転職して気づきました。人が辞める理由は、条件ではありません。給料でも、労働時間でもない。「この会社にいても自分は大事にされない」と感じた瞬間です。
- 3社経験して分かったのは、面接で落ちる理由はスキルではありません。経歴でも、資格でもない。たった一言です。
- 実際に上司が原因で辞めた経験から言います。転職活動が止まる理由は、勇気不足ではありません。転職理由の言語化が、一人では無限にグルグルする構造にあります。

### 使うべきテーマ
退職理由・転職判断など「みんなが表面的な答えで納得している領域」で逆を出す。型の威力は「当事者ラベル＋否定列挙」の組み合わせで生まれるので、当事者ラベルが具体的であるほど強くなる。

### 注意
- 「人事として」「採用担当として」は使わない。実体験ベースの当事者ラベルに必ず変換する
- 否定列挙は3つまで
- 真因の「」セリフは具体的かつ短く。長くするとフックの切れ味が落ちる

## 【型4】「あ、このまま」内省気づき判断基準型 ★★★

### 構造
```
{{判断を要する文脈の1文（〜迷ったとき、〜タイミング）}}。
{{「一つだけ」「ひとつだけ」で判断基準を絞る一文}}。
「{{口語の内省を「」で1文}}」と{{気づく/思った/感じた}}ときです。
```

### スロット
- **判断を要する文脈の1文**: 「会社を辞めるか迷ったとき」「会社を辞めるべきタイミングはひとつです」 ← 判断ものに限定
- **「一つだけ」「ひとつだけ」の絞り込み**: 「ひとつだけ結構正確な判断基準があります」「ひとつです」 ← 数字で絞ると保存されやすい
- **口語の内省「」**: 「あ、このままここにいたら私性格悪くなるな」「あ、このままここにいたら、自分が嫌いな自分になりそう」 ← 「あ、」始まりで日常の独り言感を出す。整えて書き直すと一気に弱くなる
- **気づき動詞**: 「と思ったときです」「そう感じたとき」 ← 句点で締めて次投稿に引く

### 実例（元アカウントの構造から生成）
- 会社を辞めるか迷ったとき、ひとつだけ結構正確な判断基準があります。「あ、このままここにいたら私性格悪くなるな」と思ったときです。
- 転職した今思う、会社を辞めるべきタイミングはひとつです。「あ、このままここにいたら、自分が嫌いな自分になりそう」そう感じたとき。

### 使うべきテーマ
辞めるか続けるかの内的サイン、自分を見失う前兆、限界の見極め。本編は「会議で誰かが詰められて『今日は自分じゃなくてよかった』と思う」のような日常の具体エピソードで畳みかけるのが定番。

### 注意
- 「あ、」の口語感を絶対に削らない。「このまま続けると性格が悪くなる」と整えると一気にダサくなる
- 本編エピソードはinputの中から具体的なものを引用すること
- 「性格が悪くなる」「自分が嫌いになる」など心理描写なので、医療・診断的表現（うつ、適応障害など）には踏み込まない

## 【型5】情報非対称の暴露・警告型 ★★

### 構造
```
{{警告フレーズ}}。
{{暴露する核心を1〜2文}}。
{{なぜそうなるかの理由を短く}}。
{{自分のポジションから言う動機の1文}}。
```

### スロット
- **警告フレーズ**: 「正直に言います。」「一番危ないサイン、教えます。」「めっちゃくちゃ怖い話します...」 ← 強い情緒語で一発
- **暴露する核心**: 自分が転職して初めて知った・エージェントに相談して初めて分かった情報を一言で。「転職エージェントが積極的には教えてくれないことがあります」「求人サイトを何時間眺めても出てこない情報があります」「転職活動を一人で進めると必ず詰まる場所があります」 ← 「実は、」で半端に切ると引きが強い
- **理由**: 短く「聞かれないと教えないから。自分から言う理由がないから。」 ← 句点連打
- **動機の1文**: 「でも実際に転職した経験から、これは伝えるべきだと思っています」 ← なぜ自分が言うのかの当事者目線での正当化

### 実例（raito_tenshoku用に生成）
- 正直に言います。転職エージェントは、積極的には教えてくれないことがあります。聞かれないと話さないから。自分から言う理由がないから。でも一度転職した経験から、これは知っておいてほしいと思っています。
- 一番危ないサイン、教えます。「会社行きたくない」じゃありません。それより危険なのは、（次投稿で「誰とも話したくなくなること」）

### 使うべきテーマ
転職市場の暗黙ルール・求人票には載らない情報・通説への警告。読者が「知らないと損する」と感じる題材で機能する。

### 注意
- 連発しない（1バッチに1本まで）。「怖い話」を多用するとオオカミ少年化する
- 暴露する内容は事実ベースに留める。「会社はあなたを騙している」のような誇張は避ける
- 他者（会社・エージェント・人事）への批判ではなく、「自分も知らなかった」という自分の経験に変換すると炎上リスクが低い
- 「絶対」「必ず」等の断定は避ける

## 【型6】モヤモヤ期間可視化→「一人では出てこない」反転型 ★★

### 構造
```
{{転職を迷っている間に繰り返す行動・状態を縦に並べる}}
{{「もう{{時間経過}}経ちますか」という問いかけ}}
（次投稿で）「{{気づきのセリフ}}」
{{ここから本題：一人で考え続ける構造的な問題を示す}}
```

### スロット
- **行動・状態を縦に並べる**: 改行で1行1項目。「求人サイトを開いて閉じる／退職理由をメモして消す／また月曜が来た」 ← 縦の視覚インパクトが命。数字（月数・週数）は入れると重さが増す
- **時間経過の問いかけ**: 「転職を考え始めてから、もう何ヶ月経ちますか。」「辞めようか迷い始めてから、どれくらい経ちましたか。」 ← 断定ではなく問いかけ
- **気づきのセリフ**: 「あ、これは一人で考えてたら当然そうなるんだ」 ← 自分を責めさせない方向の気づきにする
- **本題への橋渡し**: 「退職理由って、一人で考えると堂々巡りになる構造があります」「次の職場への軸は、一人では出てきにくい」

### 実例（raito_tenshoku用に生成）
- 転職を考え始めてから、どれくらい経ちますか。求人サイトを開いて閉じる。退職理由をメモして消す。また月曜が来た。
- （続き）「あ、これは一人で考えてたら当然そうなるんだ」。転職理由の整理は、一人だとどうしても堂々巡りになる構造があります。その理由を話します。

### 使うべきテーマ
一人で考え続けることの消耗、転職活動が進まない読者、一人vs相談ありの違い。本編は「退職理由・次の職場の軸・上司リスクの整理は一人では出てこない」の流れで。CTAはUZUZ無料相談（プロフィール誘導）へ自然に繋げる。

### 注意
- 「相談すれば全部解決」の直接的な書き方はしない。「整理しやすくなる」「一人で考えるより早い」の表現に留める
- 求人サイト名・転職エージェント名は出さない。プロフィール誘導で
- 特定の数字（〇ヶ月）は概算でよい。精度より「長かった時間」の視覚インパクトを重視
- 「自分が悪い」と読者を責める方向にならないよう、「構造の問題」として提示する
