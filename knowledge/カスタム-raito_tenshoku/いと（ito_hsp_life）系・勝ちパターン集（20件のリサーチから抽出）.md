# いと（ito_hsp_life）系・勝ちパターン集（20件のリサーチから抽出）

**目的**: 1投稿目（フック）と全体構成の精度を最大化するためのテンプレ集。
2025年12月〜2026年5月に@ito_hsp_lifeアカウントでいいね7,500以上を獲得した20投稿を構造分析。いいね平均約16,500（最高51,243）の超高反応パターンを抽出した。

## 使い方の原則

- 1バッチの投稿のうち、ここの型は2本以上に同じ型を使わないこと（既存rules準拠）
- パターンの「{{スロット}}」部分はコンセプトシートのテーマ・ペルソナに沿って必ず固有化する
- 実例の文言をそのままコピーするのではなく、構造を借りて新しい一文を作る
- 数字（いいね数）は内部参考情報。投稿本文に含めない

## 【型1】超短文あるある共感フック ★★★

このアカウントで最高バズを連発している型。説明ゼロ。あるあるを1〜2行で言い切って「同じ人いる？」で締めるだけ。

### 構造
```
{{あるある一文（日常・感覚・感情）}}
{{共感募集CTA}}
```

### スロット
- **あるある一文**: HSP・内向型・過敏系の日常感覚を一言で表す。説明や背景は書かない。句点で終わらず体言止めや「よね」で終わらせる
  - 「お風呂って入っちゃえば気持ちいいけど入るまでが本当に億劫よね😂」
  - 「土日どちらかは"何もしない日"が必要なひと〜？🙋🏻‍♀️」
  - 「「この人、もう無理！」って一度なったら心のシャッターは二度と開かない派。」
- **共感募集CTA**: 「同じ人いる？」「同じタイプいる？」「共感してくれる人いる？？」「〜のひと〜？🙋🏻‍♀️」「〜な人いるかな？」のどれか。疑問符は「？？」と2つ重ねてもOK

### 実例（このアカウントのリサーチから）
- 「お風呂って入っちゃえば気持ちいいけど入るまでが本当に億劫よね😂 共感してくれる人いる？？」
- 「「この人、もう無理！」って一度なったら心のシャッターは二度と開かない派。 同じタイプいる？？」
- 「土日どちらかは"何もしない日"が必要なひと〜？🙋🏻‍♀️」
- 「あまり人に言いたくない話をチャットGPTに相談して涙してる人って私だけじゃないよね…？🥲」

### 使うべきテーマ
HSP・内向型の日常感覚（疲れやすさ・感覚過敏・人疲れ・反省会・休養ニーズ）。転職文脈なら「職場でこれが辛い」を一言で切り取る形で使う

### 注意
短すぎて「内容がない」と思いがちだが、このアカウントの最高バズはすべてこの型。説明を足したくなる衝動を抑えること

## 【型2】ぶっちゃけ本音フック ★★★

「ぶっちゃけ」はこのアカウントの固有語。データ中3回登場、すべて1万いいね超え。タブーや言いにくい本音を正面から言う型。

### 構造
```
ぶっちゃけ{{言いにくい度合い補強}}、
{{タブーな本音・不満・願望}}
{{同じ人いる？CTA}}
```

### スロット
- **言いにくい度合い補強**: 「言うと、」「…」「、」など。省略してもOK
  - 「ぶっちゃけ言うと、」「ぶっちゃけ…」「ぶっちゃけ、」
- **タブーな本音**: 「普通は言わない」「でも心の中では思ってる」系の本音。職場・働き方・お金が特に刺さる
  - 「"10時出社の16時退社"くらいで働きたい…」
  - 「給料1万円上がるより、社会保険料3万円下がるほうが正直、よっぽど助かるよね？」
  - 「挨拶しない人を「無理だな」って思う人、どれくらいいますか～？？」
- **CTA**: 「同じ人いますか？？」「どれくらいいますか～？？」

### 実例（このアカウントのリサーチから）
- 「ぶっちゃけ言うと、"10時出社の16時退社"くらいで働きたい… 同じ人いますか？？」
- 「ぶっちゃけ… 挨拶しない人を「無理だな」って思う人、どれくらいいますか～？？」
- 「ぶっちゃけ、給料1万円上がるより、社会保険料3万円下がるほうが正直、よっぽど助かるよね？」

### 使うべきテーマ
働き方の本音（勤務時間・休日・給与）、職場の人間関係への正直な感想、社会制度への不満。転職文脈では「こんな職場を辞めたい理由」の本音として使いやすい

### 注意
「ぶっちゃけ」はこのアカウントの固有語なので、他アカウントでそのまま使うとキャラがブレる場合がある。アカウントごとに代替語（「正直に言うと」「本音を言えば」等）に置き換えること

## 【型3】エクスキューズ付きタブー本音フック ★★★

「これ言ったら〜かもだけど」という前置きで「言いにくさ」を演出してから本音を言う型。データ中3件登場、7,500〜12,600いいね。「ぶっちゃけ型」より少し挑発的・逆張り寄りのテーマに使う。

### 構造
```
これ言ったら{{批判リスクの表現}}かもだけど、
{{タブー・逆説的な本音}}
{{同じ人いる？CTA}}
```

### スロット
- **批判リスクの表現**: 「不謹慎」「怒られる」「批判される」など。そのまま使う
  - 「これ言ったら不謹慎かもだけど、」
  - 「これ言うと怒られるかもだけど、」
  - 「これ言ったら不謹慎かもしれないけど、」
- **タブーな本音**: 一般的には「言ってはいけない」とされる感情・意見。共感する人は強く引き込まれる内容
  - 「コロナ禍の時の"人となるべく離れてね"って時が正直、生きやすかった」
  - 「職場って真面目な人ほど仕事増えるのおかしくない？🥹」
- **CTA**: 「同じタイプの人いる？」「同じ人いる？🫢」「〜くない？」（問いかけで終わらせてもCTAになる）

### 実例（このアカウントのリサーチから）
- 「これ言ったら不謹慎かもだけど、コロナ禍の時の"人となるべく離れてね"って時が正直、生きやすかった 同じタイプの人いる？」
- 「これ言ったら不謹慎かもしれないけど、コロナ禍の"なるべく人と離れてね"って時が正直、生きやすかった 同じ人いる？🫢」
- 「これ言うと怒られるかもだけど、職場って真面目な人ほど仕事増えるのおかしくない？🥹」

### 使うべきテーマ
職場の理不尽・社会の矛盾（真面目=損、離職者が悪者扱い、メンタル壊した側が損）。転職文脈では「辞めたいと思う本当の理由」の逆張り表現として使える

### 注意
「不謹慎」ワードは内容次第でコミュニティガイドライン注意。亡くなった人・災害を絡めるテーマへの転用はしないこと

## 【型4】あるある箇条書き列挙 + 同じ人いる？ ★★

「これ、同じ人いる？」から始めて箇条書きで特性・悩みをリストアップする型。12,112いいねを記録。HSP特性の「該当チェック」として機能する。

### 構造
```
これ、同じ人いる？

・{{特性・あるある1}}
・{{特性・あるある2}}
・{{特性・あるある3}}
・{{特性・あるある4（任意）}}
・{{特性・あるある5（任意）}}
```

### スロット
- **「これ、同じ人いる？」**: 固定フレーズとして使う（このアカウントの定番）
- **箇条書き項目**: 「〜が苦手」「〜してしまう」「〜が辛い」「〜派」など、読んだ人が「それ私だ」となる特性・行動・感情。5〜6項目が最適。抽象的にならず具体的に書く
  - 「心を開くまでに時間がかかる」
  - 「休日はのんびり家で過ごしたい」
  - 「満員電車や混雑した場所が苦手で疲れる」
  - 「大人数よりも少人数派」
  - 「失敗するとしばらく引きずる」
  - 「予定が近づくとだんだん憂鬱になる」

### 実例（このアカウントのリサーチから）
- 「これ、同じ人いる？ ・心を開くまでに時間がかかる ・休日はのんびり家で過ごしたい ・満員電車や混雑した場所が苦手で疲れる ・大人数よりも少人数派 ・失敗するとしばらく引きずる ・予定が近づくとだんだん憂鬱になる」

### 使うべきテーマ
HSP・内向型の特性チェック、転職後の「向いていない職場の特徴」「こんな環境で消耗してる」など。複数の読者が一気に「それ全部当てはまる！」となる設計が肝

### 注意
項目が多すぎると読まれなくなる。5〜6項目を上限とし、最も刺さる項目を先頭に置く

## 【型5】代弁者宣言型 ★★

「誰も言わないので私が言います」という一文で権威と代弁者ポジションを確立する型。18,132いいねを記録。社会・制度・職場への提言に使う。

### 構造
```
誰も言わないので私が言います。
{{タブーな提言・社会批評}}
{{補足または決意の一文}}
```

### スロット
- **固定フレーズ**: 「誰も言わないので私が言います。」（このアカウントの固有フレーズ。変えない）
- **タブーな提言**: 「みんな思ってるけど言わない」社会・制度・職場への批評。数字や具体性があると強い
  - 「給料を1万円上げるより、社会保険料を3万下げてほしい。それなら生活がかなり楽になる。」
- **補足・決意**: 「結構本気で思ってます。」のように個人の本気度を添える

### 実例（このアカウントのリサーチから）
- 「誰も言わないので私が言います。給料を1万円上げるより、社会保険料を3万下げてほしい。それなら生活がかなり楽になる。結構本気で思ってます。」

### 使うべきテーマ
給与・社会保険・働き方制度への提言、転職市場の理不尽（採用側の問題・求人の嘘）、職場の常識への疑問。転職文脈では「転職しなきゃいけない構造的な理由」として使える

### 注意
この型は1投稿に1度のインパクトがある。同じバッチに2本使うと「またか」になるので必ず1本のみ
