# ブラックちゃん（tenshoku_black）系・勝ちパターン集（20件のリサーチから抽出）

**目的**: 1投稿目（フック）と全体構成の精度を最大化するためのテンプレ集。
2026年1月〜4月に@tenshoku_blackアカウントでいいね71〜1,489を獲得した20投稿を構造分析。「怒り・ユーモア・共感」の3軸で構成されるこのアカウント固有のフック様式を抽出した。

## 使い方の原則

- 1バッチの投稿のうち、ここの型は2本以上に同じ型を使わないこと（既存rules準拠）
- パターンの「{{スロット}}」部分はコンセプトシートのテーマ・ペルソナに沿って必ず固有化する
- 実例の文言をそのままコピーするのではなく、構造を借りて新しい一文を作る
- 数字（いいね数）は内部参考情報。投稿本文に含めない

## 【型1】「誰ですか？〇〇した人」怒り擬人化フック ★★★

このアカウント最高バズ（1,489いいね）を出した固有フレーズ。理不尽な制度・慣習の「原因を作った誰か」に問いかける形で怒りを表現する。読者の「私もずっとそれ思ってた！」を一気に解放する。

### 構造
```
誰ですか？
{{理不尽な制度・慣習を作った人物の行動}}。
{{「〜してくれてたら違ったのに」または「〜じゃなかったら〜だったのに」という惜しみ文}}、、、。
```

### スロット
- **「誰ですか？」**: 固定フレーズ。変えない
- **理不尽な行動**: 「〜を基準にした人」「〜を決めた人」「〜を作った人」。具体的な数字・条件を入れると刺さる
  - 「1日8時間で週5日勤務を基準にした人」
  - 「残業代が出ない仕組みにした人」
  - 「有給10日しかつかない制度にした人」
- **惜しみ文**: 「〜にしてくれてたらぜんぜん違ったのに、、、。」という語尾で怒りを表現しつつ憎めない空気にする
- **「、、、」**: 語尾に読点3つ。このアカウントの固有スタイルなので必ず入れる

### 実例（このアカウントのリサーチから）
- 「誰ですか？1日8時間で週5日勤務を基準にした人。1日6時間とか、週4日とかにしてくれてたらぜんぜん違ったのに、、、。」

### 使うべきテーマ
労働時間・祝日数・社会保険・残業・有給など「勤務制度への怒り」全般。転職文脈では「この制度がおかしいから辞めたくなる」の感情整理に使える

### 注意
特定の実在する個人名・企業名を入れないこと。制度・慣習レベルの怒りにとどめる

## 【型2】「神様一生のお願い」ファンタジー不満フック ★★★

997いいねを獲得したこのアカウント固有のユーモア型。労働への不満を「神様へのお願い」という非現実設定で包んで表現する。怒りを笑いに変換できるので拡散しやすく、コメントも呼びやすい。

### 構造
```
あの神様一生のお願いです！
{{あったらいいのに系の労働環境改善リクエスト}}。
そうするとさ、、、
```

または完結型：
```
あの神様一生のお願いです！
{{リクエスト}}。
{{そうなったらどうなるか・何が変わるかを1〜2文で描写}}
一緒の人いるかな？？
```

### スロット
- **「あの神様一生のお願いです！」**: 固定フレーズ。感嘆符つきで使う
- **リクエスト**: 「毎週〇〇は祝日に」「残業を〇〇に」など、「実現不可能だけど誰もが望む」労働環境改善
  - 「毎週水曜日は祝日にしてください」
  - 「週4勤務を法律にしてください」
  - 「月曜の朝だけ時間を2倍にしてください」
- **「そうするとさ、、、」**: ツリー投稿の場合は焦らしで終わらせる。単発投稿なら「体の休まりが全然違うんだよね、、、」など帰結を添える
- **CTA**: 「一緒の人いるかな？？」

### 実例（このアカウントのリサーチから）
- 「あの神様一生のお願いです！毎週水曜日は祝日にしてください。そうするとさ、、、」

### 使うべきテーマ
祝日・休日・労働時間・勤務制度の改善願望。転職文脈では「今の職場のここを変えたい」の感情表現として、または「こんな職場に転職したい」という理想の裏側として使う

### 注意
このアカウントのユーモアスタイルを維持するために「！」と「、、、」はセットで使う。真面目なトーンに変えると型が壊れる

## 【型3】「批判/炎上覚悟」エクスキューズ付き本音フック ★★★

「批判覚悟で言ってもいいですか？」「炎上覚悟で大事なこと呟きます。」という前置きで「言いにくさ」を演出してから本音を言う型。701いいねを記録。いとアカウントの「これ言ったら不謹慎かも」に対応する、このアカウント固有の強い表現。

### 構造
```
{{覚悟表明フレーズ}}

{{タブーな本音・逆説・常識破り}}
{{「一緒だよ。って人いるかな？？」CTA}}
```

### スロット
- **覚悟表明フレーズ**: 「批判覚悟で言ってもいいですか？」「炎上覚悟で大事なこと呟きます。」の2種。強度で使い分け
  - 弱め: 「批判覚悟で言ってもいいですか？」
  - 強め: 「炎上覚悟で大事なこと呟きます。」
- **タブーな本音**: 「言ってはいけないと思われがちだが、当事者はみんな思っている」内容
  - 「仕事って内容よりも、『職場の人』で続けられるか決まる。」
  - 「HSPさんが転職を繰り返すのは、能力が低いからでも仕事ができないからでもない。実は、」
- **CTA**: 「一緒だよ。って人いるかな？？」「一緒の人いるかな？？？」

### 実例（このアカウントのリサーチから）
- 「批判覚悟で言ってもいいですか？仕事って内容よりも、『職場の人』で続けられるか決まる。一緒だよ。って人いるかな？？」
- 「炎上覚悟で大事なこと呟きます。HSPさんが、転職を繰り返すのは、能力が低いからでも、仕事ができないからでもない。実は、」

### 使うべきテーマ
「仕事は人間関係で決まる」「真面目な人ほど損をする」「辞めることは逃げじゃない」などの逆説的真実。転職の決断を後押しするコンテンツに特に相性がいい

### 注意
「批判覚悟」「炎上覚悟」は乱発すると薄まる。1バッチに1本まで

## 【型4】「〇〇な人へ」ターゲット呼びかけ → 専門家引用 → 共感落とし込み ★★

「職場に居場所がない〜」「仕事に行きたくない〜」など悩みを持つ人を1行目で名指しし、心療内科の先生の言葉を「」で引用して共感を落とし込む型。519いいね。このアカウントで複数回使われている構造。

### 構造
```
{{悩みを持つ人を名指しするターゲット呼びかけ}}。
これ、{{専門家・信頼できる人物}}に言われてハッとした言葉があります。それが、
「{{専門家の言葉（「」引用）}}」
{{「自分のことだと思いました」や「それを聞いて楽になった」などの共感落とし込み}}
```

### スロット
- **ターゲット呼びかけ**: 読者の「それ私だ」を引き出す悩み・状態の一文
  - 「職場に居場所がないと感じて仕事に行きたくない人。」
  - 「人間関係が理由で転職を迷っている人。」
  - 「会社を辞めたいけど自分が弱いのかなと思っている人。」
- **専門家引用元**: 「心療内科の先生」が固有。他に「カウンセラー」「産業医」など信頼性のある人物
- **引用内容「」**: 読者の自己否定を解除する言葉。「あなたが悪いんじゃない」「それは欠陥じゃない」系の内容が特に機能する
  - 「合わない環境にいると、自分がダメだと思い込んでしまうんです」
  - 「うつになる人は意志が弱い人じゃないです。むしろ逆で、限界を超えても自分を鞭打って動き続けられる、真面目で強い人。」
  - 「HSPは病気でも障害でもない。ただ、脳の処理が人より丁寧なだけです。」
- **共感落とし込み**: 「そのとき、まさに自分のことだと思いました。」（固定に近いフレーズ）

### 実例（このアカウントのリサーチから）
- 「職場に居場所がないと感じて仕事に行きたくない人。これ、心療内科の先生に言われてハッとした言葉があります。それが、「合わない環境にいると、自分がダメだと思い込んでしまうんです」そのとき、まさに自分のことだと思いました。」
- 「心療内科の先生に言われて、楽になったこと。「HSPは病気でも障害でもない。ただ、脳の処理が人より丁寧なだけです。それは欠陥じゃなくて、仕様が違うというだけのこと。」その言葉を聞くまで、」

### 使うべきテーマ
「自分のせいじゃなかった」系の自己肯定コンテンツ。職場の人間関係で傷ついた人・うつ・HSP・転職繰り返しへの後押しとして特に有効

### 注意
引用する「専門家の言葉」は架空創作しないこと。inputにある実際の投稿本文から拾うか、ユーザーが実際に聞いた言葉を使う

## 【型5】焦らしツリーフック（「〜するとさ、、、」「実は、」型） ★★

投稿1本目を「答えを言わずに焦らして」終わらせ、続きをツリーや次の投稿で展開する型。このアカウントのデータに複数登場する構成スタイル。

### 構造
```
{{フック（型1〜4のいずれかを使う）}}
{{本文の途中・クライマックス直前}}
{{「〜するとさ、、、」「実は、」「逆に、〜は、」「特に、」のどれかで途切れさせる}}
```

### スロット
- **焦らし終止フレーズ**: 続きを期待させる語尾
  - 「そうするとさ、、、」
  - 「実は、」
  - 「逆に、〇〇な人は、」
  - 「特に、」
  - 「その言葉を聞くまで、」
- **使い方**: 型1〜4のフックと組み合わせてツリー投稿の1枚目として使う。答え・リストの中身・逆転情報を「2投稿目以降」に置く

### 実例（このアカウントのリサーチから）
- 「あの神様一生のお願いです！毎週水曜日は祝日にしてください。そうするとさ、、、」
- 「うつ症状がある人の転職、職種選びで消耗量が違うんです。避けるべき職種は、（中略）逆に、うつ症状があっても働きやすい職種は、」
- 「炎上覚悟で大事なこと呟きます。HSPさんが、転職を繰り返すのは、能力が低いからでも、仕事ができないからでもない。実は、」

### 使うべきテーマ
リスト紹介（〇〇な職種・環境・方法）、逆説情報（「実は〜だった」）、体験談の続き。転職文脈では「転職で消耗しない方法」「うつでも働きやすい職場の選び方」に使いやすい

### 注意
焦らしで終わらせた場合は必ずツリーで続きを投稿すること。「続きがない」状態はフォロワーの信頼を損なう
