# Threads自動投稿 WebUI（v1）

Threads（Meta）の投稿をAI生成・予約・自動投稿できるWebアプリです。
ローカルPC上で起動して、ブラウザから操作します。

---

## ⭐ ターミナルが苦手な人へ（まずこれを読む）

「ターミナルって何？」という方は、このフォルダの中の **次のファイルをダブルクリック** すれば、ターミナルが自動で開いて動きます：

| ダブルクリックするファイル（Mac / Windows） | やること |
|---|---|
| `初回セットアップ.command` / `初回セットアップ.bat` | 最初の準備（必要なものをインストール＋DB初期化） |
| `アプリ起動.command` / `アプリ起動.bat` | アプリを起動する（ブラウザで http://localhost:3000 が開く） |
| `アップデート.command` / `アップデート.bat` | 新しい版に更新する（設定は引き継がれます） |
| `クラウドオフロード設定.command` / `クラウドオフロード設定.bat` | PCを閉じても投稿できるようにする設定 |

- **Macで初めてダブルクリックすると「開発元を検証できないため開けません」と出ることがあります** → その `.command` ファイルを **右クリック →「開く」→（確認が出たら）「開く」** を押せばOK。2回目以降は普通にダブルクリックで動きます。
- **Windowsの方**は `.bat` の方を使ってください（中で `bash` を使うため、初回は「Git for Windows」のインストールが必要なことがあります。出てくる案内に従ってください）。
- **Claude Code を使っている方**は、Claude Code にこのフォルダを開いて「**セットアップして**」「**アプリを起動して**」「**アップデートして**」「**クラウドオフロードをセットアップして**」と言うだけでもOKです（上のファイルと同じことを代わりにやってくれます）。

下の「セットアップ手順」は、ターミナルを自分で操作する場合の詳しい説明です。

## 動作環境

- macOS（Apple Silicon / Intel どちらもOK） ／ Windows 10・11（`.sh` を使うため [Git for Windows](https://git-scm.com/download/win) のインストールが必要）
- **Node.js 20以上**
- **Claude Code CLI（Pro または Maxプラン契約必須）**
- Threads（Meta）アカウント＋Threads API アクセストークン

## セットアップ手順

### 1. Node.js をインストール（既に入ってる人は飛ばす）

ターミナルで以下を実行してバージョンを確認：

```
node -v
```

`v20.x.x` 以上が表示されればOK。出ない／古い場合は https://nodejs.org/ からLTS版をインストールしてください。

### 2. Claude Code CLI をインストール＆ログイン

ターミナルで：

```
npm install -g @anthropic-ai/claude-code
claude login
```

ブラウザが開くのでClaude（Pro/Max）アカウントでログイン。CLIから生成できるか動作確認：

```
claude -p "hello"
```

何か返答があればOK。

### 3. このフォルダでセットアップを実行

このREADME.mdがあるフォルダにターミナルで移動して：

```
bash setup.sh
```

これで以下が自動的に行われます：
- 依存パッケージのインストール（`npm install`）
- データベース初期化（Prisma migrate）
- ナレッジの投入（バズフック・市場フック・生成ルール・稼ぐ系プレイブック等 計6本）

セットアップは数分かかります。最後に「いま起動しますか？[Y/n]」と聞かれたらYを押せば、サーバー起動＋ブラウザ自動オープンまで一気通貫で進みます。

### 4. Threads API トークンを取得（初回のみ）

Threads Graph APIを使うには、Meta開発者ポータルでアプリ登録が必要です。
ざっくり以下の手順：

1. https://developers.facebook.com/ にログイン
2. 「マイアプリ」→「アプリを作成」→「その他」→「ビジネス」
3. 作成したアプリで「Threads API」プロダクトを追加
4. 必要な権限：`threads_basic`, `threads_content_publish`, `threads_manage_replies`
5. 自分のThreadsアカウントを「テストユーザー」として追加
6. トークン生成画面でアクセストークン＋ユーザーIDをコピー

詳細はMeta公式ドキュメント：https://developers.facebook.com/docs/threads/get-started/

### 5. Webアプリを起動

```
bash start.sh
```

サーバー起動後にブラウザが自動的に開きます（http://localhost:3000）。停止するときは `Ctrl+C`。

> 💡 セットアップ完了時に「いま起動しますか？」でYを押した場合、このステップは自動で実行されます。

> ⚠ ターミナルに `Ready` と出ているのにブラウザがずっとロード中のまま表示されない場合は、PCのメモリ不足や高負荷で初回コンパイルが止まっている可能性があります。Zoom/LINE/重いブラウザタブを閉じるか、Macを再起動してから `bash start.sh` を実行し直してください。

### 6. 設定画面でアカウントを登録

WebUI右上の「設定」→「アカウント」タブで：

- **アカウント名**: 任意（管理用）
- **Threads ユーザーID**: 4で取得したユーザーID
- **アクセストークン**: 4で取得したアクセストークン
- **コンセプトシート**: 「💡 記入テンプレを挿入」ボタンで質問形式のテンプレが入るので、それに沿って埋める（精度に直結）
- **投稿時間帯**: デフォルト6/12/18/21時
- **1日投稿数**: デフォルト4
- **AI自動生成**: 毎朝5時に自動生成するか（任意）

「保存」を押せば登録完了。

## 使い方

### AI投稿生成
1. ダッシュボードで「AI生成」ボタン
2. アカウント＋投稿数を選択
3. 1〜3分待つ（Claude Opusがバックグラウンドで動きます）
4. 「下書き」タブに生成された投稿が並びます

### 投稿の編集
- 下書きの「編集」ボタンで本文を修正可能
- スレッド投稿は各投稿を個別に編集できる

### キュー追加
- 個別: 「キューに追加」→ 日時指定
- 一括: 「全件キューに追加」→ アカウントの投稿時間帯に沿って自動で時刻割当（プレビュー確認後に実行）

### 自動投稿
- バックグラウンドで毎分キューをチェックし、`publishAt`が到来した投稿を自動でThreadsに投稿します
- **PCを起動した状態で `bash start.sh` が動いてる必要があります**（PCを切ると投稿は止まります）
- **PCを閉じても投稿させたい場合は「クラウドオフロード」**（次節）を有効化してください

### ☁ クラウドオフロード（PCを閉じても投稿、任意機能）

スプレッドシート＋GAS（Google Apps Script）の時間トリガーが投稿を担当する仕組みです。Macが起動していなくても予約投稿が動きます。

**有効にしない選択でもOK**（PC起動中の運用なら不要）。有効にする場合:

```
bash setup-cloud.sh
```

スクリプトが clasp 認証→スプシ作成→GASコードPush→Web Appデプロイ手順 を対話的に進めます。
完了後、Webアプリの「設定 → アカウント編集 → ☁ クラウドオフロード」で URL/Key を貼って疎通確認すれば運用開始できます。

詳細手順・トラブルシュート: [`gas/CLOUD_OFFLOAD.md`](gas/CLOUD_OFFLOAD.md)

クラウドオフロード使用時の注意:
- アカウントごとに専用スプシを1つ作成（複数アカウント運用なら数だけ作る）
- 一度GASに転記された予約投稿はPCの状態に関係なく実行される
- 投稿結果は5分おきにWebアプリに自動同期される
- Threadsトークンは GAS 側で7日おき自動リフレッシュ（60日期限切れ防止）

### 📱 外出先のスマホから使う（リモートアクセス、任意機能）

外出先のスマホからアプリを開いて投稿の生成・編集・キュー追加をしたい場合に使います。
画面はスマホサイズに最適化済みなので、そのまま指で操作できます。

```
bash remote.sh
```

（Mac は `リモートアクセス.command`、Windows は `リモートアクセス.bat` のダブルクリックでもOK）

実行すると:
1. 最初の1回だけ「合言葉（パスワード）」を決めます（`.env.local` に保存。次回からは聞きません）
2. アプリにそのパスワードのカギがかかります（Basic 認証）
3. `https://〜.trycloudflare.com` の一時URLが発行されます
4. スマホのブラウザでそのURLを開く → ユーザー名は何でもOK・パスワードに合言葉を入力すれば使えます

注意:
- **パスワードを設定しないと外部公開しません**（安全のため。`REMOTE_PASSWORD` 環境変数で制御）
- 公開URLはウィンドウを開いている間だけ有効（閉じる／Ctrl+C で停止、URLは毎回変わる）
- **PCがスリープ/電源オフの間は外からも開けません**。常時投稿だけが目的なら上の「クラウドオフロード」を使ってください
- 普段のローカル利用（`bash start.sh`）はこれまでどおり。パスワード設定が無ければカギはかかりません

## ⚠️ テスト中の注意点

### 1. PCをつけっぱにする必要あり（クラウドオフロード未使用時）
予約投稿はあなたのPC内のスケジューラが動かしているので、PCを切ると投稿が飛びません。
PCを閉じても投稿させたい場合は前節「☁ クラウドオフロード」を参照。

### 2. 凍結対策
- 同一アカウントの最小投稿間隔は60分（自動制御）
- 一括キュー追加時も65分以上の間隔で割当
- ハッシュタグ自動除外
- エンゲージメントベイトはナレッジで禁止済み

### 3. AI生成の精度
- コンセプトシートを丁寧に書くほど生成品質が上がります（特に「失敗体験」「持論」「避けたい定型句」）
- 生成された投稿は**そのまま投稿せず、必ずレビュー**してください
- 期待値を下回るときはコンセプトシートを調整して再生成

### 4. Claude Code CLI のサブスク利用
- AI生成1回あたり、Claudeサブスク枠を消費します（Opusモデル使用）
- 1日数十本程度なら余裕で収まりますが、無制限ではありません

## トラブルシュート

### `npm install` でエラー
- Node.jsのバージョンが古い可能性。`node -v`で確認、20以上に更新

### `claude -p` でエラー
- ログインしてない or サブスク切れ。`claude login`でログインし直す

### 投稿APIエラー
- アクセストークンの期限切れ。Meta開発者ポータルで再発行
- 権限不足の可能性。`threads_content_publish`が付与されているか確認

### 生成結果が空 or 短すぎる
- コンセプトシートが空 or 短すぎる可能性。設定画面の「💡記入テンプレを挿入」を活用

### 生成が遅い
- Opus使用のため1〜3分かかることがあります（Claude Code CLIの処理）

### `Ready` と出たのにブラウザがずっとロード中
- PCの空きメモリ不足や高負荷で、Next.js の初回コンパイルが進まないことがあります。
- Zoom / LINE / 重いブラウザタブを閉じるか、Macを再起動してから `bash start.sh` を実行し直してください。
- `start.sh` は起動時に空きメモリと負荷を軽くチェックし、危険水準なら警告を出します。

### 「ナレッジを編集したのに `.md` ファイルが変わらない」
- 仕様です。Webアプリで追加・編集・削除したナレッジは**このアプリの中（データベース）に保存**されます。フォルダ内の `prisma/*.md` は初回セットアップ用の初期テンプレートで、ここでの編集では書き換わりません（編集が消えるわけではなく、アプリ側に保存されています）。

### 「GASコードのリンクが少ない行数しかない」「スプレッドシートのメニューが急に変わった」「`ナレッジCSV_API` のセルがおかしい」「初回実行で完了0件・シートが空」など
- **以前に使っていた別ツールのファイルが残っていると起きます。** このツールを使う前に、次のものはすべて削除 / OFF にしてください：
  - 年末配布の「スレッズ分析ツール」のフォルダ
  - 旧スプレッドシート版（v2 / v3 など）のフォルダ・スプレッドシート
  - 旧ツールで設置した Apps Script のコードと**時間トリガー**（トリガーは必ず OFF / 削除）
- 古いマニュアル（マインドマップ等）のリンクや手順は最新版と一致しないことがあります。**このフォルダ同梱の `README.md` と、Discord に投下される最新のアップデートノートを正としてください。** セットアップ後の流れは「Webアプリ起動 → 設定 → アカウント登録 → コンセプトシートに『💡記入テンプレ』で記入」です（旧版にあった“対話形式のコンセプト作成”は廃止）。
